# W2b · 变形提公因式（同核改写）

对应弱项：[素质跟踪报告 · W2b](../../docs/素质跟踪/豆豆/素质跟踪报告.md)

前置：先完成 [W2 · 代数方程变形](../W2-代数方程变形/)（会做 `(a−5)² = a−5` 这类「两边已同构」题）。

触发例题：`(9a+15)² = 10+6a`（两边看起来不像，其实都含核 `3a+5`）

## 使用方法

1. **先读讲义**：[变形提公因式技巧与避坑](./变形提公因式技巧与避坑.pdf)
2. 学生只看练习卷，家长对照答案批改。
3. 建议顺序：讲义 → 卷 01（提数字 + 改写对齐）→ 卷 02（同核方程）→ 卷 03（限时综合）。
4. 错题回到讲义对应「坑几」，闭卷讲给 AI，再做 1 道变式。
5. **口令**：先提数字 → 再对齐括号 → 再移项提因式。

## 升级门槛

能独立把变形题改写成同核后用因式分解求出全部解并验根；连续两次同类变式正确率 ≥ 90%；能口头说出触发题的「核」是什么。
