# W2b 讲义 · 变形提公因式：技巧与避坑

> 触发题：`(9a+15)² = 10+6a`。  
> W2 会做 `(a−5)² = a−5`，说明「同构提因式」已通；卡在本题，说明还要会**先改写成同一个核**。

---

## 一、和 W2 差在哪一层

| W2（已同构） | W2b（要变形） |
|---|---|
| `(a−5)² = a−5` | `(9a+15)² = 10+6a` |
| 两边已经是同一个 `□` | 两边「长得不像」，其实都含 `3a+5` |
| 直接移项提公因式 | **先提数字、对齐括号，再提** |

口令（背下来）：

> **先提数字 → 再对齐括号 → 再移项提因式。**

---

## 二、什么叫「核」

把一次式提成 `数字 × (字母式)` 后，括号里的部分叫**核**。

| 原式 | 改写 | 核 |
|---|---|---|
| `9a+15` | `3(3a+5)` | `3a+5` |
| `10+6a` | `2(5+3a)` → `2(3a+5)` | `3a+5` |
| `4x+6` | `2(2x+3)` | `2x+3` |
| `6x+9` | `3(2x+3)` | `2x+3` |

两边核相同，才谈得上「同核方程」。

---

## 三、正路五步（触发题）

以求 `(9a+15)² = 10+6a` 为例：

1. **左边提数字**：`9a+15 = 3(3a+5)`，所以左边 `= [3(3a+5)]² = 9(3a+5)²`
2. **右边提数字并对齐**：`10+6a = 2(5+3a) = 2(3a+5)`
3. **设核**：设 `u = 3a+5`，方程变成 `9u² = 2u`
4. **移项提因式**：`9u² − 2u = 0` → `u(9u−2) = 0`
5. **解并验根**：`u = 0` 或 `u = 2/9`  
   → `3a+5 = 0` 或 `3a+5 = 2/9`  
   → `a = −5/3` 或 `a = −43/27`  
   （代回原式验）

不设 `u` 也可以：直接写成  
`9(3a+5)² − 2(3a+5) = 0` → `(3a+5)[9(3a+5)−2] = 0`。

---

## 四、数字桥：先练「提数字」

| 数字感觉 | 字母写法 |
|---|---|
| `9+15 = 3×(3+5)` | `9a+15 = 3(3a+5)` |
| `10+6 = 2×(5+3)` | `10+6a = 2(5+3a)` |
| `5+3 = 3+5`（交换） | `5+3a = 3a+5` |

**书写要求：** 提数字时写出「数字 × 括号」，禁止只在脑子里消。

---

## 五、九大坑

### 坑 1：只看字母，不提数字

看到 `9a+15`，只想提 `a`，提不出；应先找数字公因式 `3`。

### 坑 2：右边不改写，硬展开左边

展开 `(9a+15)²` 会得到很长多项式，又容易算错。  
优先改写成同核，再提因式。

### 坑 3：忘记交换律对齐

`5+3a` 和 `3a+5` 是同一个核。写不出来，就「对不齐」。

### 坑 4：平方后数字系数漏掉

`[3(3a+5)]² = 9(3a+5)²`，不是 `3(3a+5)²`。  
外层数字也要平方。

### 坑 5：两边同除核（又走 W2 老路）

从 `9u² = 2u` 两边除以 `u`，会丢掉 `u=0`。  
正路仍是移项：`9u²−2u=0`。

### 坑 6：核提错（数字没提干净）

`9a+15` 提成 `9(a+15)` 是错的。应提最大公因式：`3(3a+5)`。

### 坑 7：只解一个解

`u(9u−2)=0` 有两解。只写一个不算完整。

### 坑 8：换元后忘记代回

求出 `u` 后必须解 `3a+5 = …`，答案是 `a`，不是 `u`。

### 坑 9：把「像」当成「同核」

`9a+15` 与 `10+6a` 看起来不像；要对齐后才知道同核。  
反过来：`a−5` 与 `5−a` 看起来像，其实差一个负号（回看 W2 坑 6）。

---

## 六、一眼识别

| 题型 | 第一步 |
|---|---|
| `(ka+kb)² = …` | 先提：`k(a+b)` |
| 右边是一次式 | 也提数字，看核是否相同 |
| 核相同、系数不同 | 设 `u=核`，得 `Au² = Bu` |
| 想两边同除 `u` | 停！改移项 |

---

## 七、样板题

### 样板 A（触发题）

```text
(9a+15)² = 10+6a
左边：9a+15 = 3(3a+5) → 9(3a+5)²
右边：10+6a = 2(3a+5)
设 u=3a+5：9u² = 2u
9u² − 2u = 0 → u(9u−2)=0
u=0 或 2/9
a=−5/3 或 −43/27
```

### 样板 B（稍简）

```text
(4x+6)² = 6x+9
左边：4x+6 = 2(2x+3) → 4(2x+3)²
右边：6x+9 = 3(2x+3)
设 u=2x+3：4u² = 3u
4u² − 3u = 0 → u(4u−3)=0
u=0 或 3/4
x=−3/2 或 −9/8
```

## 八、一句话总原则

> **看起来不像先改写；数字提出核对齐；同核再走 W2 正路。**
