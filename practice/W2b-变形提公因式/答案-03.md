## B

5. `2x+4=2(x+2)` → 设 `u=x+2`：`4u²=2u` 更干净：原式即 `[2(x+2)]²=2(x+2)` → `4u²=2u` → `2u(2u−1)=0`  
   → `u=0` 或 `1/2` → `x=−2` 或 `−3/2`  
   （也可看成核 `2x+4`：`(2x+4)[(2x+4)−1]=0` → `2x+4=0` 或 `2x+3=0`）
6. 左边 `9(2a+1)²`，右边 `2a+1`；`9u²=u` → `u(9u−1)=0`  
   → `u=0` 或 `1/9` → `a=−1/2` 或 `−4/9`
7. 左边 `16(2t+1)²`，右边 `2(2t+1)`；`16u²=2u` → `2u(8u−1)=0`  
   → `u=0` 或 `1/8` → `t=−1/2` 或 `−7/16`
8. 左边 `9(3a+5)²`，右边 `3a+5`；`9u²=u` → `u(9u−1)=0`  
   → `u=0` 或 `1/9` → `a=−5/3` 或 `−44/27`
9. 同卷 02 第 7 题：`x=−3/2` 或 `−9/8`
10. 左边 `25(2y+3)²`，右边 `2(2y+3)`；`25u²=2u` → `u(25u−2)=0`  
    → `u=0` 或 `2/25` → `y=−3/2` 或 `−73/50`
11. `x²−3x=0` → `x(x−3)=0` → `x=0` 或 `3`
12. `(a−2)(a−3)=0` → `a=2` 或 `3`
