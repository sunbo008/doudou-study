# W2b 答案 02 · 同核方程

## A

1. `3(3a+5)`；`9(3a+5)²`
2. `2(3a+5)`
3. `9u² = 2u`
4. `u(9u−2)=0`（或 `9u²−2u=0`）；`u=0` 或 `2/9`；`a=−5/3` 或 `−43/27`

## B

5. 设 `u=3a+5`：`u²=u` → `u(u−1)=0` → `u=0` 或 `1`  
   → `a=−5/3` 或 `−4/3`
6. 左边 `4(2x+3)²`，右边 `2x+3`；设 `u=2x+3`：`4u²=u` → `u(4u−1)=0`  
   → `u=0` 或 `1/4` → `x=−3/2` 或 `−11/8`
7. 左边 `4(2x+3)²`，右边 `3(2x+3)`；`4u²=3u` → `u(4u−3)=0`  
   → `u=0` 或 `3/4` → `x=−3/2` 或 `−9/8`
8. 同 A：`a=−5/3` 或 `−43/27`
9. 左边 `9(2y+3)²`，右边 `2(2y+3)`；`9u²=2u` → `u(9u−2)=0`  
   → `u=0` 或 `2/9` → `y=−3/2` 或 `−25/18`
10. 左边 `25(m+2)²`，右边 `5(m+2)`；`25u²=5u` → `5u(5u−1)=0`  
    → `u=0` 或 `1/5` → `m=−2` 或 `−9/5`

## C

11. **不完整**。丢掉了 `u=0`（对应原方程里核为 0 的解）。
12. **错**。应是 `[3(3a+5)]² = 9(3a+5)²`。

## 批改提示

- 第 5、10 题本质是 W2 同构，只是多了提数字；若不会提但展开做对，书面可给分，口头补提数字。
- 分数解写反（如把 `−43/27` 写成 `−27/43`）→ 回查由 `3a+5=2/9` 解 `a` 的步骤。
