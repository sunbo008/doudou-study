# W1 · 带小数的乘除法专项练习

对应弱项：[素质跟踪报告 · W1](../../docs/素质跟踪/豆豆/素质跟踪报告.md)

## 使用方法

1. **先读讲义**：[小数乘除法技巧与避坑](./小数乘除法技巧与避坑.pdf)（坑点、步骤、验算）。
2. 学生只看「练习卷」，家长/AI 对照「答案」批改。
3. 建议顺序：讲义 → 卷 01（转化+乘法）→ 卷 02（除法与 ÷ 百分数）→ 卷 03（限时综合）。
4. 每卷做完后：对答案 → 归因（K/L/B/T/E）→ 回到讲义对应「坑几」→ 闭卷讲给 AI → 再做 1 道变式。
5. 限时建议写在卷首；超时未完成先收卷，再单独补做错题。
