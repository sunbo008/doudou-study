## 使用

1. 打开或打印 PDF，每次做 1 组（20 题），目标约 2 分钟，不用计算器。
2. 答案在文档末尾，学生做题时不要翻看。
3. 错题回 [小数乘除法技巧与避坑](../小数乘除法技巧与避坑.pdf)，按坑点归因（位数 / 百分数未转化 / 商定位）。
4. 建议节奏：每天 1～2 组；连续 3 组 ≥ 18/20 且稳定在 2 分钟内，再用练习卷 03 复测。
