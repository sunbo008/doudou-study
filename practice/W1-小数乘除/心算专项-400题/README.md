# W1 心算专项 · 400 题（强化学习）

在 [心算专项 200 题](../心算专项-200题/) 做完后仍有错题时使用。题型仍对齐练习卷 03；新题不与前 200 题表达式重复，并略提高百分数相关比重。

## 文件

| 文件 | 用途 |
|---|---|
| [心算专项-400题.pdf](./心算专项-400题.pdf) | **可打印合订本**（题目在前，答案在后） |
| [心算专项-400题.md](./心算专项-400题.md) | Markdown 源稿 |

## 使用

1. 打开或打印 PDF，每次做 1 组（20 题），限时 15～20 分钟，不用计算器。
2. 答案在文档末尾，学生做题时不要翻看。
3. 错题回 [小数乘除法技巧与避坑](../小数乘除法技巧与避坑.pdf)，按坑点归因（位数 / 百分数未转化 / 商定位）。
4. 建议节奏：每天 1～2 组；连续 3 组 ≥ 18/20 后再用练习卷 03 复测。
