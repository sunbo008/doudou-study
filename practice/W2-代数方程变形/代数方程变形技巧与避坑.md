# W2 讲义 · 代数方程变形：技巧与避坑

> 触发题：`(a−5)² = a−5`。你想到两边同除，说明有结构感；卡住和丢解，说明要换「正路」，并补字母约分。

---

## 一、先记住：这不是数字心算题

| 看起来像 | 其实是 |
|---|---|
| 脑子里消掉 `a−5` | 字母式子的约分：`(□)² ÷ □ = □` |
| 算不出来很「晕」 | 步骤没写开：应写成 `(a−5)·(a−5)/(a−5)` |
| 除完得一个答案 | 方程变形是否合法：除数能不能为 0 |

与 W1（小数乘除）不同层：W1 练数字运算；W2 练**式子变形规则**。

---

## 二、正路四步（以后默认用这个）

以求 `(a−5)² = a−5` 为例：

1. **移到一边**：`(a−5)² − (a−5) = 0`
2. **提公因式**：`(a−5)·[(a−5) − 1] = 0`  
   也就是 `(a−5)(a−6) = 0`
3. **积为零**：`a−5 = 0` 或 `a−6 = 0`
4. **写解并验根**：`a = 5` 或 `a = 6`；代入原式都成立

### 换元版（同一正路）

设 `x = a−5`，则 `x² = x` → `x² − x = 0` → `x(x−1)=0` → `x=0` 或 `1` → `a=5` 或 `6`。

---

## 三、数字桥：先通规则，再写字母

| 数字 | 字母 | 规则 |
|---|---|---|
| `3² ÷ 3 = 3` | `(a−5)² ÷ (a−5) = a−5` | `(□)² ÷ □ = □`（□≠0） |
| `5² ÷ 5 = 5` | `x² ÷ x = x` | 同上 |
| `9 ÷ 3 = 3` | 只是普通除法 | 别和「平方除以底」混 |

**书写要求：** 约分时必须先展开平方：

```text
(a−5)² ÷ (a−5)
= (a−5)·(a−5) ÷ (a−5)
= a−5          （要求 a−5 ≠ 0）
```

禁止在脑子里「凭感觉消掉」。

---

## 四、九大坑

### 坑 1：两边同除含未知数的式子（核心坑）

原式两边同除 `a−5`，在 `a≠5` 时得到：

`a−5 = 1` → `a = 6`

但 `a = 5` 也满足原式（`0² = 0`），被「除掉」丢掉了。

**规定：** 含未知数的式子，不能随便拿到两边去除。优先移项因式分解。

### 坑 2：约分时不会写开

卡在「`(a−5)²` 除以 `a−5` 等于啥」→ 先写两个括号相乘，再约。

### 坑 3：只求一解就停

`□² = □` 通常有两解：`□ = 0` 或 `□ = 1`。少写一个就不完整。

### 坑 4：把 `x² = x` 两边除以 `x`，只得 `x = 1`

同样丢掉 `x = 0`。

### 坑 5：验根不做

解完必须代回原式。尤其用过「除法」时，更要检查被除掉的那种情况。

### 坑 6：符号看反

`(a−5)² = 5−a` 不是同一型。  
因为 `5−a = −(a−5)`，要先变形，不能机械套「等于自身」。

### 坑 7：展开后算砸

展开 `(a−5)² = a²−10a+25` 可以，但步骤更长、更容易算错。  
优先提公因式，不必硬展开。

### 坑 8：公因式提错

`(a−5)² − (a−5)` 提完应是 `(a−5)(a−5−1)`，不是 `(a−5)(a−5)`。  
第二项只有一次，提出后括号里剩 `1` 变成减 `1`。

### 坑 9：把「平方」当成「乘 2」

`(a−5)²` 是自己乘自己，不是 `2(a−5)`。

## 五、一眼识别

| 题型 | 第一步 |
|---|---|
| `□² = □` | 移项提公因式，或设 `x=□` |
| `x² = x` | `x(x−1)=0` → `0` 或 `1` |
| `(a−k)² = a−k` | 与上同构 → `a=k` 或 `a=k+1` |
| `(2x)² = 2x` | 设 `u=2x`，`u=0` 或 `1` |
| 想两边同除 | 停！改移项；若已除，必须补查除数为 0 |

## 六、样板题

### 样板 A（正路）

```text
(a−5)² = a−5
(a−5)² − (a−5) = 0
(a−5)(a−6) = 0
a−5 = 0 或 a−6 = 0
a = 5 或 a = 6
验：a=5 → 0=0 ✓；a=6 → 1=1 ✓
```

### 样板 B（若已经同除了，怎么补救）

```text
两边 ÷ (a−5)（默认 a≠5）→ a−5 = 1 → a = 6
补查：a−5 = 0？即 a=5，代入原式成立 → 也是解
完整答案：a=5 或 a=6
```

更好的办法：下次不要走「同除」，直接走样板 A。

---

## 七、一句话总原则

> **同型先移项；提因式找零点；含未知数别乱除；求得的解要验根。**
