# W2 · 代数式约分与方程合法变形

对应弱项：[素质跟踪报告 · W2](../../docs/素质跟踪/豆豆/素质跟踪报告.md)

触发例题：`(a−5)² = a−5`（卡在两边同除 `a−5`）

## 使用方法

1. **先读讲义**：[代数方程变形技巧与避坑](./代数方程变形技巧与避坑.pdf)
2. 学生只看练习卷，家长对照答案批改。
3. 建议顺序：讲义 → 卷 01（数字桥 + 约分）→ 卷 02（移项因式分解，禁止乱除）→ 卷 03（限时综合）。
4. 错题回到讲义对应「坑几」，闭卷讲给 AI，再做 1 道变式。
5. **正路优先**：移项 → 提公因式 → 积为零 → 验根。不要把「两边同除」当主方法。

## 升级门槛

能独立用因式分解写出全部解并验根；能说明「为什么两边同除 `a−5` 会丢解」；连续两次同类变式正确率 ≥ 90%。
