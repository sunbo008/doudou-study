# W2 答案 02 · 移项因式分解

## A

1. `(a−5)`
2. `a−6` 或 `(a−5)−1`
3. `a−6`
4. `5`；`6`

## B

5. `x²−x=0` → `x(x−1)=0` → `x=0` 或 `1`
6. `(a−3)(a−4)=0` → `a=3` 或 `4`
7. `(b−1)b=0` 即 `(b−1)(b−1−1)=0` → `b=1` 或 `2`
8. `(a−5)(a−6)=0` → `a=5` 或 `6`
9. 设 `u=2x`：`u(u−1)=0` → `2x=0` 或 `2x=1` → `x=0` 或 `1/2`  
   也可：`4x²−2x=0` → `2x(2x−1)=0`
10. `y(y−1)=0` → `y=0` 或 `1`
11. `(m+2)(m+1)=0` → `m=−2` 或 `−1`
12. `3t(3t−1)=0` → `t=0` 或 `1/3`

## C

13. **不完整**。丢掉了 `a=5`（除数为 0 的情况，但代入原式成立）。
14. **错**。应提成 `(a−5)[(a−5)−1] = (a−5)(a−6)`。
