# E1 · Episode 双文件模板

每一集 **两个文件**（给 AI **只有一个**）：

| 文件 | 读者 | 内容 |
|---|---|---|
| `EYY-…-AI脚本.md` | **只发这一份给 AI** | 内嵌 `# SYSTEM` 约束 + `# SCRIPT` 正文（单文件自包含） |
| `EYY-…-小朋友版.md` | **豆豆** | 英文故事、读完回答、落笔三句（无标准答案） |

样例：[E05-AI脚本](./Unit02-夏商周/E05-商鞅变法/E05-商鞅变法-AI脚本.md) · [E05-小朋友版](./Unit02-夏商周/E05-商鞅变法/E05-商鞅变法-小朋友版.md)

---

## 写稿顺序

```
① 复制 AI脚本-约束头模板.md → 新建 EYY-AI脚本.md
② 按 野史八卦写作规范.md 写 Part ①～④（③ 引子短 + 八卦主菜；末路 beat 声明**震撼词 + 三味**，见 0.5/0.6）
③ 命名规范 + 词汇规范 + **八卦 G0–G7** 自检（超纲 ≤5，末路震撼词除外）
④ 写问题链 → 小朋友版 → gen_e1_pdfs.py
```

---

## AI脚本结构（固定）

```
# EYY · 标题 · AI 脚本（单文件）     ← 家长说明：整份发给 AI

# SYSTEM · 执行指令                  ← 约束自动内嵌，写稿时从模板粘贴
  硬规则 / 流程锁 / 纠偏口令 / 开始指令

# SCRIPT · 本集脚本
  §1 [READ] 朗读正文
  §2 [ASK] 问题链
  §3 [FEEDBACK] 模板
  §4 Fact Box
  §5 固定话术
  §6 写稿记录（AI 忽略）
```

写稿模板：[`AI脚本-约束头模板.md`](./AI脚本-约束头模板.md)
