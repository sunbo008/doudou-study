# E1 · 野史英语（纠错钩子 × 课纲对齐）

对应弱项：[素质跟踪报告 · E1](../../docs/素质跟踪/豆豆/素质跟踪报告.md)

设计规格：[E1 设计文档](../../docs/superpowers/specs/2026-08-22-e1-gossip-history-english-design.md)

## 一句话

用 **「先抛误区 → 打脸 → 野史八卦 → 正史收网」** 的英文小剧场，预习统编版七上历史。

**两条硬约束**：① **姓名 + 称号** 智慧并用（如 *Qin Xiaogong, the ruler of Qin*；*Ying Zheng, the emperor*）—— 禁止只有 the Duke/the King 而不知道是谁；② 正文尽量用 **当下已学单词**，超纲词附 **超纲词复习** 表。

## 教学法

1. **给 AI**：每集 **只发一个** `EYY-AI脚本.md`（内嵌 `# SYSTEM` 约束 + `# SCRIPT` 正文）。
2. **给豆豆**：`EYY-小朋友版.md`（听读 + 读完回答 + 落笔）。
3. 写新集：[`AI脚本-约束头模板`](./AI脚本-约束头模板.md) + [`野史八卦写作规范`](./野史八卦写作规范.md) + 命名/词汇检查。
4. D7、D14 复测，不做新集。

## 文件一览

| 文件 | 用途 |
|---|---|
| `课纲对照表.md` | 七上每一课 ↔ Episode |
| `AI脚本-约束头模板.md` | 写稿时粘贴到 AI 脚本顶部（生成单文件） |
| `Episode-双文件模板.md` | 双文件结构说明 |
| `野史八卦写作规范.md` | 钩子、节奏、PEP 词汇、三段式野史 |
| `词汇规范.md` | 已学词池 + 超纲词附表 |
| `…/EYY-…-AI脚本.md` | **整份发给 AI**（SYSTEM + SCRIPT 合一） |
| `…/EYY-…-小朋友版.md` | 豆豆：故事 + 读完回答 + 落笔（可生成 `.pdf`） |
| `…/EYY-正史卡.md` | 纯硬核 fact（考前用） |

## 升级门槛

- 连续 3 集：90 秒英文口述过关；闭卷落笔三句；Fact Box 2 条正确。
- 关键人物均有姓名；emperor / king / ruler 与姓名同现，不单用 the Duke / the King。
