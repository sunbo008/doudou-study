# W4 技巧与避坑（口诀卡）

对应：数轴定位 · 计件工资 · 折反射 · 距离比

---

## 口诀（先背再做）

1. **计件乘实际，定额只进超欠。**  
   工资 = 实际件数 × 单价 ±（超额奖或欠产扣）
2. **折点是原点与像的中点。**  
   `C = (A + A') / 2`
3. **距离比先分区，去绝对值后必须验根。**  
   `|P−B| = k · |P−A|` → 按 P 在数轴位置分类 → 解完代回检查
4. **带分数画在两整数正中或按比例切。**  
   `1 1/2 = 1.5` → 1 与 2 的正中间，不要目测成 1.4

---

## 坑（对照错题本）

| 坑 | 典型错法 | 正确意识 |
|---|---|---|
| 坑1 | `180×5 + 超额奖` | 基数是 **191（实际）**，不是定额 180 |
| 坑2 | 距离比硬凑出一个 `P=5` | 分类讨论；每个解都代入验 |
| 坑3 | `1 1/2` 画偏 | 先化小数，再找中点/刻度 |
| 坑4 | 折叠只猜方向 | 先定折后 `A'` 坐标，再用中点求 `C` |

---

## 验根小模板（距离比）

已知 `A`、`B`，条件 `|P−B| = 2|P−A|`：

1. 写出方程（把坐标代入）
2. 分两种符号：`左 = 2·右` 与 `左 = −2·右`
3. 每个解算一遍 `|P−B|` 和 `2|P−A|`，相等才留
4. 若问 `n` 格距：`n = |P−A| + |P−B|`
