# W4 · 有理数数轴应用（ABC 混编 3 天）

对应弱项：[素质跟踪报告 · W4](../../docs/素质跟踪/豆豆/素质跟踪报告.md)

触发来源：初一首月考错题 15 / 17 / 19(3) / 21(3)（12～14 已过关，不进本专项）

## 三个能力点（混在每天卷里）

| 代号 | 能力 | 原题对应 |
|---|---|---|
| A | 数轴精确定位（分数/小数刻度） | 17 |
| B | 应用题条件锚定（定额 vs 实际件数） | 19(3) |
| C | 折反射中点 + 距离比分类验根 | 15、21(3) |

## 使用方法

1. **先读 1 页口诀**：[技巧与避坑](./技巧与避坑.pdf)
2. 学生只看当日练习卷；家长对照 [答案](./答案.pdf) 批改。
3. 顺序：Day01 → Day02 → Day03（限时）。不要拆开只刷某一类。
4. 错题回到口诀对应「坑」，口头讲给家长/AI，再在次日卷里找同类题。
5. **距离比（混编题 7 / 14 / 18 类）卡住** → 先做 [C专项-距离比](./C专项-距离比/)，再回 Day02 / Day03。
