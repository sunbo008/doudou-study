# 距离比：几何与 ± 两式

给数轴上的点 A、B，找点 P，并会算 `n = PA + PB`。

---

## 1. 距离怎么写

数轴上两个点，中间隔了几格，叫距离。

- P 到 A 的距离写成：`PA = |P − A|`
- P 到 B 的距离写成：`PB = |P − B|`

绝对值的意思：不管谁大谁小，只留「隔了几格」。

例：`A=0`，`P=2`，隔了 2 格：

```numberline
points A=0 P=2
span A P 2 PA
```

---

## 2. 题目在说什么

若题目写 `PB = 2 · PA`，用人话就是：

> P 到 B 隔的格数，是 P 到 A 隔的格数的 2 倍。

先用数轴看这句话什么意思。仍取 `A=0`，`B=6`，并先随便摆一个满足条件的点，比如 `P=2`：

```numberline
points A=0 P=2 B=6
span A P 2 PA
span P B 4 PB
```

读图：

- `PA` = 2 格（P 到 A）
- `PB` = 4 格（P 到 B）
- 4 正好是 2 的 **2 倍** → 所以说「`PB` 是 `PA` 的 2 倍」

写成数学式，就是把两段距离换成绝对值：

`|P − B| = 2|P − A|`

（k 是几，就是几倍。下一节再问：这样的 P 一共有几个、都在哪。）

---

## 3. 数轴上看看（k=1 和 k=2）

### 先看等距：`PA = PB`

P 在 A、B 正中间。这里中点是 `P=3`：到 0 是 3 格，到 6 也是 3 格。

```numberline
points A=0 P=3 B=6
span A P 3 PA
span P B 3 PB
```

### 再看两倍：`PB = 2 · PA`

一般有 **两个** 位置。

**位置①：在 A、B 之间，更靠 A** — `P=2`（就是上一节那张图：`PA=2`，`PB=4`）

**位置②：在外侧（A 的左边）** — `P=−6`

到 A：6 格；到 B：12 格。正好 `12 = 2 × 6`。

```numberline
points P=-6 A=0 B=6
span P A 6 PA
span P B 12 PB
```

自己再画一遍：先标 `A`、`B`，再标两个 `P`。数格子核对「是不是 2 倍」——比死记位置靠谱。

---

## 4. 为什么要写两式：左 = ±k·右

距离只看「隔了几格」，所以先写成：

`|P − B| = 2|P − A|`

算的时候要把绝对值拆掉。拆掉之后，左边的 `P−B` 和右边的 `2(P−A)` 可能：

- 本身就相等，或
- 差一个负号（一个是另一个的相反数）

所以要写 **两道普通方程**（不要起别的名字，就看式子本身）：

1. `P − B = 2(P − A)`  
2. `P − B = −2(P − A)`　　← 多了一个负号

仍用 `A=0`，`B=6`。上一节已经找到两个真解：外侧 `P=−6`，中间 `P=2`。  
下面把每个 P **代进两式里看看**，就明白为什么两式都要写。

### 先记一件小事：绝对值相等，有向差有两种可能

同一条数轴，`A=0`，`B=6`。

**相等**：中点 `M=3`。`A→M` 与 `M→B` 都是向右 3 格：

```numberline
points A=0 M=3 B=6
dir A M +3 A→M = +3
dir M B +3 M→B = +3
```

**差一个负号**：从 A 到 B 是 `+6`，从 B 回 A 是 `−6`：

```numberline
points A=0 B=6
dir A B +6 A→B = +6
dir B A -6 B→A = -6
```

格数一样，方向相反 → `A→B = −(B→A)`。

距离比里也一样：`|P−B|` 与 `2|P−A|` 格数对上了，拆开后就要考虑「相等」和「差一个负号」两种。

### 外侧 `P=−6`：满足第 1 式

```numberline
points P=-6 A=0 B=6
span P A 6 PA
span P B 12 PB
```

代入：`P−A = −6`，`P−B = −12`。

- 第 1 式：`P−B` ？`= 2(P−A)` → `−12` ？`= 2×(−6)` → `−12 = −12` ✓  
- 第 2 式：`P−B` ？`= −2(P−A)` → `−12` ？`= −2×(−6)` → `−12 = 12` ✗  

所以这个 P 是 **第 1 式** 解出来的。

### 中间 `P=2`：满足第 2 式

```numberline
points A=0 P=2 B=6
span A P 2 PA
span P B 4 PB
```

代入：`P−A = +2`，`P−B = −4`。

- 第 1 式：`−4` ？`= 2×(+2)` → `−4 = 4` ✗  
- 第 2 式：`−4` ？`= −2×(+2)` → `−4 = −4` ✓  

所以这个 P 是 **第 2 式** 解出来的。

### 做题时怎么用

做题时你还不知道 P 在外侧还是中间，所以：

1. 两式都解；  
2. 每个答案代回原来的绝对值式 `|P−B|` 与 `2|P−A|`，相等才留。

只解一式，就会漏掉另一个位置上的 P。

---

## 5. 和口诀「分区 → 去绝对值 → 验根」

口诀三步：

1. **分区** —— 在数轴上按关键点切开，假设 P 落在某一段；  
2. **去绝对值** —— 这一段里 `|P−A|`、`|P−B|` 的正负已经定了，可以写成不带竖线的式子；  
3. **验根** —— 解出来的数，先看还在不在这一段，再代回原式核对。

本专项前面讲的「± 两式」是另一条路；**殊途同归，最后都要验根**。  
下面用数轴把「分区」走一遍。仍用 `A=0`，`B=6`，方程：

`|x − 6| = 2|x|`　　（也就是 `PB = 2 · PA`）

### 第 1 步：分区 —— 关键点切开数轴

绝对值在 `0`（点 A）和 `6`（点 B）处「拐弯」，所以用这两点把数轴切成 **三段**：

```numberline
points A=0 B=6
cut 0 6
bands (1) (2) (3)
```

对应：`(1) x ≤ 0`　`(2) 0 ≤ x ≤ 6`　`(3) x ≥ 6`

做题时三段都要试；每一段里绝对值的写法不一样。

### 第 2 步：去绝对值 —— 每一段写成普通方程

在某一段里，P 相对 A、B 的左右关系固定了，竖线可以拆掉：

**① 左段 `x ≤ 0`**（P 在 A 左边）

```numberline
points P=-3 A=0 B=6
```

- `|x| = −x`（x 是负数或 0）  
- `|x−6| = 6−x`（x 在 6 左边）

方程变成：`6 − x = 2(−x)` → `6 − x = −2x` → `6 = −x` → `x = −6`  
还在左段吗？`−6 ≤ 0` ✓

**② 中段 `0 ≤ x ≤ 6`**（P 在 A、B 之间）

```numberline
points A=0 P=2 B=6
```

- `|x| = x`  
- `|x−6| = 6−x`

方程变成：`6 − x = 2x` → `6 = 3x` → `x = 2`  
还在中段吗？`0 ≤ 2 ≤ 6` ✓

**③ 右段 `x ≥ 6`**（P 在 B 右边）

```numberline
points A=0 B=6 P=9
```

- `|x| = x`  
- `|x−6| = x−6`

方程变成：`x − 6 = 2x` → `−6 = x` → `x = −6`  
还在右段吗？`−6 ≥ 6`？✗ → **丢掉**（算对了方程，但不属于这一段）

### 第 3 步：验根 —— 代回原式

留下的候选：`x = −6`，`x = 2`。

| 候选 | `|x−6|` | `2|x|` | 留？ |
|---|---|---|---|
| `−6` | `12` | `12` | 留 |
| `2` | `4` | `4` | 留 |

和前面用 ± 两式得到的两个真解一样。

### 和「± 两式」怎么选

| | ± 两式 | 分区 |
|---|---|---|
| 做法 | 一次写两式：`左=右` 与 `左=−右` | 数轴切段，每段拆绝对值 |
| 好处 | 步骤少，纯倍比题好用 | 看见 P 在哪一段；「几倍多/少」更好拆 |
| 共同 | 解完都要验根；不属于该段的、代回不对的，都要舍 |

可以记：

> **先画 A、B，再决定用哪条路；不管哪条路，最后代回原式看一眼。**

---

## 6. 求 n

每个留下的 P：

`n = |P − A| + |P − B|`

先取绝对值，再相加。

---

## 7. 人话怎么列式（会写即可）

| 人话 | 先写成 |
|---|---|
| 几倍 | `PB = k · PA` |
| 等距 | `PA = PB` |
| 比 `PA:PB = m:n` | `n · PA = m · PB` |
| 多 / 少多少 | `PB = PA ± d` |
| 几倍多 / 少多少 | `PB = k · PA ± d` |

先写成带 `|P−A|`、`|P−B|` 的式子，再展开计算。

---

## 8. 展开之后的心算

有括号先打开；打开后把含 P（或 x）的挪一边、常数挪一边；再除。

常见样子：`mx + a = nx − b`，或 `m(x+a)=n(x−b)` 等。
