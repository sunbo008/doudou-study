## Day01

1. `x = 4`
2. `x = 6`
3. `x = 4`
4. `x = −6`
5. `x = −1/3`
6. `x = 9`
7. `x = −8`

8. `x = 8` 或 `x = −2`  
   验：`|8−3|=5`，`|−2−3|=5`
9. `x = 2`  
   验：`|2+1|=3`，`|2−5|=3`

10. `|x−6| = 2|x|`；展开：`x−6 = 2x` 与 `x−6 = −2x`
11. `|x+4| = |x−2|`；展开：`x+4 = x−2`（无解支）与 `x+4 = −(x−2)`
12. `|x−3| = 2|x+2| + 1`（注意是「还多 1」，不是纯倍）

13. `|x−6| = 2|x|`  
    - `x = −6`；验：`12 = 2×6`，留；`n = 18`  
    - `x = 2`；验：`4 = 2×2`，留；`n = 6`
14. `|x+4| = |x−2|` → `x = −1`；`n = 6`
15. `|x−3| = 2|x+2|`  
    - `x = −7`；验：`10 = 2×5`，留；`n = 15`  
    - `x = −1/3`；验：`10/3 = 2×(5/3)`，留；`n = 5`
16. `|x−5| = |x| + 2` → `x = 1.5`；验：`3.5 = 1.5+2`；`n = 5`
17. `|x−4| = 2|x| − 5`  
    - `x = −9`；验：右边 `13`，左边 `13`，留；`n = 22`  
    - `x = 3`；验：右边 `1`，左边 `1`，留；`n = 4`  
    （家长：乱拆得 `x=1`，右边 `−3 < 0` → 舍。）

18. `|P−60| = 2|P|`  
    - `P = −60`；`n = 180`  
    - `P = 20`；`n = 60`
19. `|P+4| = |P−2|` → `P = −1`；`n = 6`
20. 绝对值相等只有「相等」或「差一个负号」两种，所以写两式；验根看两边是否真相等。

## Day02

1. `x = 9`
2. `x = 11/2`
3. `x = 7/5`
4. `x = 3/7`

5. `x = 5` 或 `x = −3`  
   验：`|5−1|=4`，`|−3−1|=4`
6. `x = 1`  
   验：`|1+3|=4`，`|1−5|=4`
7. `|x−4| = 2|x| − 5`（详细步骤）

   **先看右边**：须 `2|x|−5 ≥ 0`，即 `|x| ≥ 2.5`。  
   两边加 5 得：`|x−4| + 5 = 2|x|`。  
   分界点 `0`、`4`，分三段去绝对值。

   **① `x ≤ 0`**：`|x|=−x`，`|x−4|=4−x`  
   `4−x+5 = 2(−x)` → `9−x = −2x` → `x = −9`  
   在本段 ✓，且 `|−9|≥2.5` ✓  
   验原式：左 `|−9−4|=13`，右 `2×9−5=13` → **留 `x=−9`**

   **② `0 ≤ x ≤ 4`**：`|x|=x`，`|x−4|=4−x`  
   `4−x+5 = 2x` → `9−x = 2x` → `x = 3`  
   在本段 ✓，且 `3≥2.5` ✓  
   验原式：左 `|3−4|=1`，右 `2×3−5=1` → **留 `x=3`**

   **③ `x ≥ 4`**：`|x|=x`，`|x−4|=x−4`  
   `x−4+5 = 2x` → `x+1 = 2x` → `x = 1`  
   `1≥4`？不在本段 → 舍  
   （若硬留：右 `2×1−5=−3<0`，左 `|1−4|=3`，距离不能等于负数 → 同样舍。  
   乱拆 `x−4=2x−5` 也会得到这个假根 `x=1`。）

   **结论**：`x = −9` 或 `x = 3`。  
   （提醒：本题右边是 `2|x|−5`，不能当成纯倍比去写 `左=±2·右`。）

8. `|x−6| = 2|x| − 3`（详细步骤；主练「不在取值范围则舍」）

   **先看右边**：须 `2|x|−3 ≥ 0`，即 `|x| ≥ 1.5`。  
   两边加 3 得：`|x−6| + 3 = 2|x|`。  
   分界点 `0`、`6`，分三段。

   **① `x ≤ 0`**：`|x|=−x`，`|x−6|=6−x`  
   `6−x+3 = 2(−x)` → `9−x = −2x` → `x = −9`  
   在本段 ✓（`−9≤0`），`|−9|≥1.5` ✓  
   验：左 `|−9−6|=15`，右 `2×9−3=15` → **留 `x=−9`**

   **② `0 ≤ x ≤ 6`**：`|x|=x`，`|x−6|=6−x`  
   `6−x+3 = 2x` → `9−x = 2x` → `x = 3`  
   在本段 ✓（`0≤3≤6`），`3≥1.5` ✓  
   验：左 `|3−6|=3`，右 `2×3−3=3` → **留 `x=3`**

   **③ `x ≥ 6`**：`|x|=x`，`|x−6|=x−6`  
   `x−6+3 = 2x` → `x−3 = 2x` → `x = −3`  
   问：`−3 ≥ 6`？**不在本段取值范围** → **舍**  
   （算出数不等于能用。本段假设了 `x≥6`，结果 `−3` 不满足假设，整段结论作废。）

   **结论**：`x = −9` 或 `x = 3`。

19. （较难；对齐题 7/8）营地 `A=200`，山口 `B=800`，列式 `|P−800| = 2|P−200| − 300`。  
   右边须 ≥0 → `|P−200| ≥ 150`。分界点 `200`、`800`。  
   - `P ≤ 200` → `P = −700`（在段内）→ 验：左 `1500`，右 `1500` → **留**；`n = 2400`  
   - `200 ≤ P ≤ 800` → `P = 500` → 验：左 `300`，右 `300` → **留**；`n = 600`  
   - `P ≥ 800` → 算出 `P = −100`，**不在本段取值范围** → **舍**（代入原式左 900 ≠ 右 300）  
   **结论**：`P = −700`（`n=2400`）或 `P = 500`（`n=600`）。  
   （家长：死套纯倍 ±、或第三段硬留假根，均错；本题主练「算出但不在段内则舍」，兼练几倍少列式。）
