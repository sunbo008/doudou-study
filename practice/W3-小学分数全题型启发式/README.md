# W3 · 小学分数全题型启发式

对应弱项：[素质跟踪报告 · W3](../../docs/素质跟踪/豆豆/素质跟踪报告.md)

覆盖范围：小学数学地图 **S03 分数** 全部知识点与题型（不含「比」）。

## 教学法：启发式

1. 先读 **逻辑文**（只有概念，没有例题）。
2. 按序做 **试题 01→05**（每套一套卷，内分部分由易到难）。
3. **全部做完**后再发 **学后总结**。提前发会毁掉启发感。

## 使用顺序

1. [分数意义的底层逻辑](./00-分数意义底层逻辑.pdf)（[md](./00-分数意义底层逻辑.md)）
2. [试题01 · 认识与意义](./试题01-认识与意义.pdf)
3. [试题02 · 约分通分与加减](./试题02-约分通分与加减.pdf)
4. [试题03 · 乘法](./试题03-乘法.pdf)（含连乘先约）
5. [试题04 · 除法](./试题04-除法.pdf)
6. [试题05 · 总复习](./试题05-总复习.pdf)
7. [学后总结 · 技巧与避坑](./学后总结-技巧与避坑.pdf) ← **最后**

家长：[答案.pdf](./答案.pdf)　验收：[覆盖清单.pdf](./覆盖清单.pdf)
