### W1. 带小数的乘除法（含百分数）

| 字段 | 内容 |
|---|---|
| 科目 | 数学 |
| 知识点 | 小数乘法、小数除法、百分数与小数互化后的乘除运算 |
| 典型例题 | `4.2 × 3.5`；`2.8 ÷ 6%` |
| 失分主标签 | **E**（计算执行） |
| 次标签 | **B**（百分数边界：`6%` 须先化为 `0.06` 再运算） |

| 可能断点 | 1）小数乘法的位数与定位；2）小数除法商的定位；3）百分数未先化为小数/分数；4）心算与竖式切换不稳 |

| 复测日 | 完成卷 01、02 后做卷 03；通过则再隔 3 天变式复测 |

#### 修复计划（W1）

1. **先读讲义**：`practice/W1-小数乘除/小数乘除法技巧与避坑.pdf`，重点过「坑 1～9」和两道样板题。
2. **先过关转化**：百分数 ↔ 小数 ↔ 分数（如 `6% = 0.06 = 6/100`），口头 + 书面各练一轮。
3. **小数乘法专项**：每天 8～10 题，含一位小数 × 一位小数（如 `4.2 × 3.5`），要求竖式或可检验的步骤，限时完成。
4. **小数除法 / 除以百分数**：每天 6～8 题，固定流程：`先把百分数化小数 → 再除 → 估商验算`（例：`2.8 ÷ 6% = 2.8 ÷ 0.06`）。
5. **答辩式闭环**：每类挑 1 题，闭卷把「步骤与为什么这样化」讲给 AI；再做 1 道变式；隔日无提示书面复测。
6. **升级标准**：连续两次限时独立正确率 ≥ 90%，且至少隔 3 天仍能独立完成同类变式，才可将本弱项从「偏弱」调整为「独立同类 / 延迟稳定」。

### W2. 代数结构识别与方程变形（含「同因式」方程）

| 字段 | 内容 |
|---|---|
| 科目 | 数学 |
| 知识点 | 完全平方、换元、移项、因式分解、方程多解与验根 |
| 典型例题 | `(a−5)² = a−5`，求 `a` |
| 失分主标签 | **K/L**（代数式约分不熟：`(a−5)² ÷ (a−5)` 化不成 `a−5`；路径上依赖「两边同除」） |
| 次标签 | **B**（两边同除含未知数的式子不合法/会丢 `a−5=0` 的解） |
| 掌握状态 | 0～1（有思路苗头，卡在化简与合法变形） |
| 证据日期 | 2026-08-09（本人反馈：两边同除 `a−5` 时卡住） |
| 表现描述 | 已想到「两边都有 `a−5`，可以同除」，但在执行 `(a−5)² ÷ (a−5)` 时卡住；即便除过去也只会得到 `a−5=1`（即 `a=6`），丢掉 `a=5`。 |
| 能力解读（不是智力标签） | **主要不是 W1 那种数字心算弱。** 卡点是「字母式子的约分/幂的运算」和「方程变形是否合法」。感觉像心算，是因为在脑子里硬消字母，又没写成 `(a−5)(a−5)/(a−5)`。与小数乘除是不同能力层，可并存，但不要混成同一个「心算差」。 |
| 已确认断点 | 1）`(□)² ÷ □ = □` 不熟练（可用数字先通：`3²÷3=3`）；2）习惯「两边同除」而不会「移项因式分解」；3）未意识到 `a−5=0` 时不能当除数，会丢解 |
| 标准解（供家长） | 推荐：移项 `(a−5)²−(a−5)=0` → `(a−5)(a−5−1)=0` → `(a−5)(a−6)=0` → `a=5` 或 `a=6`。若已同除，必须补一句：还要单独检查 `a−5=0` 是否也是解。 |
| 下一步动作 | 见下方「修复计划」；练习材料已就绪 |
| 练习材料 | [practice/W2-代数方程变形/](../../../practice/W2-代数方程变形/)（讲义 + 3 天练习卷 + 答案） |
| 配套讲义 | [代数方程变形技巧与避坑](../../../practice/W2-代数方程变形/代数方程变形技巧与避坑.pdf) |
| 复测日 | 讲义 → 卷 01 → 卷 02 → 卷 03；卷 03 达标后再隔 3 天变式复测 |

#### 修复计划（W2）

1. **先读讲义**：`practice/W2-代数方程变形/代数方程变形技巧与避坑.pdf`，重点坑 1、2、8。
2. **先拆「假心算」**：用纸写出 `(a−5)² = (a−5)·(a−5)`，再约分，禁止纯口算硬消（卷 01）。
3. **立刻换正路**：不要继续强化「两边同除」。改练：移到一边 → 提公因式 → 积为零 → 验根（卷 02）。
4. **专治丢解**：`a=5` 代入原式成立；规定含未知数的式子不能随便当除数。
5. **限时综合**：卷 03；第 13 题（为何同除不完整）必须过关。
6. **升级标准**：能独立用因式分解写出两解并验根；能说出「为什么两边同除 `a−5` 不完整」。过关后若遇变形题卡住，进入 W2b。

#### 建议练题样本（可轮换）

| 类型 | 例题 | 答案要点 |
|---|---|---|
| 直接同构 | `(a−5)² = a−5` | `a=5` 或 `a=6` |
| 换数 | `(a−3)² = a−3` | `a=3` 或 `a=4` |
| 最简形 | `x² = x` | `x=0` 或 `x=1` |
| 含系数 | `(2x)² = 2x` | `2x=0` 或 `2x=1` ⇒ `x=0` 或 `x=1/2` |
| 符号陷阱 | `(a−5)² = 5−a` | `5−a = −(a−5)`，需额外变形，防机械套用 |

### W2b. 变形提公因式（同核改写）

| 字段 | 内容 |
|---|---|
| 科目 | 数学 |
| 知识点 | 提数字公因式、交换对齐、同核换元、移项因式分解 |
| 典型例题 | `(9a+15)² = 10+6a`，求 `a` |
| 失分主标签 | **T**（迁移失败：同构题会，变形后不会） |
| 次标签 | **K**（提数字公因式 / 平方后系数不熟） |
| 掌握状态 | 0～1（只能提简单明确公因式） |
| 证据日期 | 2026-08-11（家长观察） |
| 表现描述 | 对 `(a−5)² = a−5` 这类两边已同构的题，经 W2 训练可走移项提因式；一旦左右要先改写才能露出同一个核（如 `9a+15` 与 `10+6a` 都含 `3a+5`），就卡住。 |
| 能力解读（不是智力标签） | **不是「不会提公因式」，而是缺「先变形再提」这一层。** 断点在：提数字 → 对齐括号（`5+3a=3a+5`）→ 再走 W2 正路。与 W2 可并存：W2 管同构合法变形，W2b 管露出同核。 |
| 已确认断点 | 1）一次式不会先提数字（`9a+15→3(3a+5)`）；2）两边「长得不像」时找不到共同核；3）平方后外层数字系数漏平方（写成 `3(…)²` 而非 `9(…)²`） |
| 标准解（供家长） | `9a+15=3(3a+5)`，`10+6a=2(3a+5)`；设 `u=3a+5` → `9u²=2u` → `u(9u−2)=0` → `u=0` 或 `2/9` → `a=−5/3` 或 `−43/27`。 |
| 下一步动作 | 见下方「修复计划」；练习材料已就绪 |
| 练习材料 | [practice/W2b-变形提公因式/](../../../practice/W2b-变形提公因式/)（讲义 + 3 天练习卷 + 答案） |
| 配套讲义 | [变形提公因式技巧与避坑](../../../practice/W2b-变形提公因式/变形提公因式技巧与避坑.pdf) |
| 复测日 | 建议 W2 卷 02/03 过关后再开 W2b；讲义 → 卷 01 → 卷 02 → 卷 03；达标后再隔 3 天变式复测 |
| 前置 | W2（同构移项因式分解）基本过关 |

#### 修复计划（W2b）

1. **先读讲义**：`practice/W2b-变形提公因式/变形提公因式技巧与避坑.pdf`，背口令「先提数字 → 再对齐括号 → 再移项提因式」。
2. **只练改写不解方程**：卷 01（提数字 + 两边改写 + 判断同核）。
3. **同核方程**：卷 02；触发题 `(9a+15)²=10+6a` 必须能独立走完并验根。
4. **限时综合**：卷 03；混入 W2 回看题，防止变形学会后把正路忘掉。
5. **答辩式闭环**：闭卷讲清「这题的核是什么、怎么看出来的」；再做 1 道变式。
6. **升级标准**：连续两次同类变式正确率 ≥ 90%；能口头说出触发题的核是 `3a+5`。

#### 建议练题样本（可轮换）

| 类型 | 例题 | 答案要点 |
|---|---|---|
| 裸提数字 | `9a+15`，`10+6a` | `3(3a+5)`，`2(3a+5)` |
| 同核已露 | `(3a+5)² = 3a+5` | `a=−5/3` 或 `−4/3` |
| 触发变形 | `(9a+15)² = 10+6a` | `a=−5/3` 或 `−43/27` |
| 变式 | `(4x+6)² = 6x+9` | `x=−3/2` 或 `−9/8` |
| 系数陷阱 | `(9a+15)²` 改写 | 必须是 `9(3a+5)²`，不是 `3(3a+5)²` |
