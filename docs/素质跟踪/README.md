# 学生素质跟踪报告

本目录用于保存学生的素质跟踪报告，记录学科弱项、证据、掌握状态与复测计划。  
报告按「学生 → 报告」分层存放，不与方案类文档混放。

## 目录约定

```text
docs/素质跟踪/
├── README.md                 # 本说明
└── <学生名>/
    ├── 素质跟踪报告.md       # 当前主报告（持续更新）
    └── 归档/                 # 按日期归档的历史快照（可选）
```

## 更新原则

1. 弱项必须有具体表现（例题、错因），不要只写「数学不好」。
2. 每条弱项标注科目、知识点、失分主标签（K/L/B/T/E）、掌握状态、证据日期与下一步动作。
3. 重大复测或阶段复盘后，可把当日主报告复制到 `归档/YYYY-MM-DD.md`，再更新主报告。
4. 证据不足时写「待复测」，不因一次对错永久定级。

## 失分主标签（与分班计划一致）

- **K**：知识缺失
- **L**：逻辑断裂
- **B**：边界不清（条件、单位、百分数等）
- **T**：迁移失败
- **E**：执行失误（计算、书写、审题）
