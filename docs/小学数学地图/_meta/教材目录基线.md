# 小学数学教材目录基线

六年级目录以用户提供的教育部审定 2022 版人教版实书为准；一至五年级按权威公开电子教材目录以 `verified_public` 录入。上册 1～5 取人教社插图重绘专题电子教材；一下～三下取国家中小学智慧教育平台人教版课标修订公开电子教材；四下～五下取同平台人教版公开电子教材。公开目录与手边实书差异只改 `pep_units` 与核验状态，不改稳定 `kp_id`。

表中「覆盖入口」指向该单元首个细知识点；正式单元与综合实践只有在目标 `active` 知识点的 `pep_units` 与目录行精确一致时才算覆盖。复习单元仅作聚合导航，允许链接年级索引锚点。
