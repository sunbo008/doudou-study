# 小学数学专项地图 · 人教版对齐说明

本地图以**人教版**小学数学教材为单元对齐基准。知识点通过 frontmatter 中的 `pep_units` 字段挂接年级、册次与单元名。

## 对齐原则

### 六年级上下册（实书严对齐）

- **以手边人教版实书单元名为准**（当前学生：豆豆；教育部审定 2022 版六年级上、下册）。
- 新建或修订 `pep_units` 时，对照实书目录填写 `grade`、`volume`、`unit`。
- 单元名与实书不一致时，**只改 `pep_units.unit` 字符串**，不改 `kp_id`、不改文件名。
- 六上正式单元含「位置与方向（二）」和「数学广角——数与形」；六下无独立「统计」单元，正式目录含「数学广角——鸽巢问题」。
- 完整逐行目录、证据和覆盖入口见 [`教材目录基线.md`](./教材目录基线.md)。两册目录条目的核验值均为 `verified_book`。

### 一年级～五年级（公开目录已核验）

- 三期已按权威公开电子教材目录录入 `教材目录基线.md`，核验状态为 `verified_public`。
- 上册 1～5：人教社插图重绘专题电子教材（`download.pep.com.cn/xsxjc/22xjcsx*1x`）。
- 一下～三下：国家中小学智慧教育平台人教版课标修订公开电子教材；四下～五下：同平台人教版公开电子教材。
- 证据与可见目录见 [`三期来源核验记录.md`](./三期来源核验记录.md)。
- 未与用户手边实书比对前，不得把一至五年级写成 `verified_book`。
- 实书差异只改 `pep_units` / 核验状态，**禁止**改 `kp_id` 或文件名。


## `pep_units` 字段示例

```yaml
pep_units:
  - { grade: 6, volume: 上, unit: "百分数（一）" }
  - { grade: 5, volume: 下, unit: "分数的意义和性质" }
```

- `grade`：1～6
- `volume`：`上` 或 `下`
- `unit`：教材单元标题，与实书一致为佳

## 与双视图的关系

- **专项索引**：按 S01～S14 组织，不依赖单元顺序。
- **年级索引**：按年级 → 上下册 → 单元聚合同一批 `kp_*.md` 链接。
- 两视图共用同一套知识点文件；`pep_units` 是年级视图的权威标签来源。

## 分期说明

| 阶段 | 对齐深度 |
|---|---|
| 一期 | 六上常见目录占位；一～五占位单元名 |
| 二期 | 六上、六下实书严对齐；逐单元填厚并补充分班高频 |
| 三期 | 一～五公开目录已核验并回填；实书复核只调 `pep_units` |
