# 小学数学专项地图 · 命名规范

本文档约定 `docs/小学数学地图/` 下目录、文件与字段的命名规则。**一经发布，`kp_id` 与文件名主干不得修改**；废弃用 `status: deprecated` 标注。

## 1. 专项目录（`specialty`）

- **格式**：`S{两位数字}-{中文名}`
- **示例**：`S02-小数与百分数`、`S06-简易方程与代数结构`
- **位置**：`docs/小学数学地图/specialties/Sxx-中文名/`
- **规则**：
  - 专项 ID（`S01`～`S14`）发布后不重编号；
  - 若废弃某专项，在 README 中说明，不回收编号。

## 2. 知识点文件与 `kp_id`

- **文件名格式**：`kp_s{专项两位}_{英文短名}.md`
- **示例**：
  - `kp_s02_decimal_div_percent.md`（小数除以百分数）
  - `kp_s06_same_core_rewrite.md`（同核改写）
- **`kp_id`**：与文件名主干（不含 `.md`）完全一致，例如 `kp_s02_decimal_div_percent`
- **规则**：
  - 发布后禁止改 `kp_id` 字符串；
  - 标题润色、单元名调整均不改 `kp_id`；
  - 废弃条目设 `status: deprecated`，文件可保留作历史引用。

## 3. 难度分级

| 级别 | 名称 | 说明 |
|---|---|---|
| L1 | 基础 | 课内原题套路，步骤单一 |
| L2 | 熟练 | 条件变形或多一步转化 |
| L3 | 综合 | 两知识点组合或易混陷阱 |
| L4 | 思维横向 | 须先识别结构 / 改写再运算，而非套公式直算 |

每个知识点至少具备 **L1 + L2**；L3 / L4 能写则写，否则在典型题型表中显式标「待补」。

## 4. 单道例题强制子块

每道例题（含 L1～L4）必须包含以下子块，顺序建议保持一致：

| 子块 | 要求 |
|---|---|
| **题目** | 完整题干 |
| **难度** | L1 / L2 / L3 / L4 |
| **解题技巧** | 可复用的方法口诀或决策顺序（先看什么、再改写什么、最后算什么） |
| **步骤要点** | 关键演算步骤（不必逐步展开到竖式细节，除非该坑就在定位 / 位数） |
| **避坑思路** | 本题最容易错在哪、如何自检；可点名「坑 n」若已有讲义编号 |
| **答案** | 最终结果（多解须列全并说明验根） |

风格对齐 `practice/` 下「技巧与避坑」讲义：**技巧可迁移，避坑要针对本题**，禁止只写「细心一点」。

## 5. 知识点 `status`

| 值 | 含义 |
|---|---|
| `draft` | 草稿，结构或内容未验收 |
| `active` | 已发布，可正常引用 |
| `deprecated` | 已废弃，保留文件与 ID 供历史链接 |

## 6. `source_verification`

| 值 | 含义 |
|---|---|
| `verified_book` | 已由用户提供的实书目录核验 |
| `verified_public` | 已由可靠公开目录核验，尚未与手边实书比对 |
| `pending` | 暂缺可靠目录，仅能保留占位 |

`source_verification: pending` 不得与 `status: active` 同时出现；待核验条目必须保持 `draft` 或 `deprecated`。
