# 小学数学专项地图

覆盖小学 1～6 年级数学知识点的**可检索、可扩展**总表。按「专项能力」组织主索引，按「年级 / 单元」提供副视图；厚实正文落在各专项下的 `kp_*.md` 知识点条目中。

## 这是什么

- **专项地图**：把小学数学拆成 14 个能力专项（S01～S14），每个专项下有若干知识点文件。
- **双视图**：同一批知识点既可从「我会哪类题」进入，也可从「几年级第几单元」进入。
- **与练习分离**：地图写「会什么、怎么考、怎么避坑」；已开练的讲义与卷子仍在 [`practice/`](../../practice/)，通过 frontmatter 回链。

设计背景与完整约定见 [小学数学专项地图设计规格](../superpowers/specs/2026-08-11-小学数学专项地图-design.md)。

## 如何用

### 专项入口（主）

1. 打开 [`专项索引.md`](./专项索引.md)。
2. 进入对应 `specialties/Sxx-中文名/` 专项文件夹。
3. 阅读该专项 README 与具体 `kp_*.md` 知识点。

适合：按弱项补课、按能力类型系统复习、查找 L4 思维横向题。

### 年级入口（副）

1. 打开 [`年级索引.md`](./年级索引.md)。
2. 按年级 → 上下册 → 单元找到知识点链接。

适合：对照人教版课本进度、按学期复习。

两视图**数据源相同**，索引只做导航，不复制例题正文。

## 新建知识点 checklist

1. 在正确专项目录下创建 `kp_sXX_english_name.md`（见命名规范）。
2. 从 [`kp-template.md`](./_meta/kp-template.md) 复制 frontmatter 与正文结构。
3. 填写 `pep_units`、`grades`；有练习则填 `practice` / `weak_ref`。
4. 每道例题写全：题目、难度、解题技巧、步骤要点、避坑思路、答案。
5. 在专项索引与年级索引中补上链接（后续任务维护索引文件）。
