# S10 统计与可能性

## 范围

**含什么：** 统计表与条形图、折线图、扇形图（认识与读图）、平均数、简单可能性（一定、可能、不可能；等可能性）。

**不含什么：** 复杂概率计算；数据收集实验设计（综合实践部分可归 S12）；负数概念与含负数的数轴 / 坐标（归 S12）。统计图表的读图与数据分析归本专项。
