# S03 分数

## 范围

**含什么：** 分数的意义与读写、真分数假分数带分数、约分与通分、同分母与异分母加减、分数乘除、分数应用（求一个数的几分之几、部分占整体等）。

**不含什么：** 小数与百分数（归 S02）；整数运算（归 S01）；比与比例（归 S05）；立体图形中的分数应用若侧重体积公式则归 S08。
