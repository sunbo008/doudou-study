# 百分数与小数互化

## 一句话

看见 `%` 先转化：百分数 ↔ 小数（必要时再 ↔ 分数），再谈乘除。

## 典型题型（按难度）

| 难度 | 题型描述 | 状态 |
|---|---|---|
| L1 | 百分数 → 小数（如 `6% = ?`） | 已写 |
| L2 | 小数 → 百分数（如 `0.35 = ?%`） | 已写 |
| L3 | 比较大小或易混转化（`8%` vs `0.8`） | 已写 |
| L4 | — | 待补 |

## 例题

### 例题 1

#### 题目

把 `6%` 化成小数。

#### 难度

L1

#### 解题技巧

口诀：去掉 `%`，小数点左移两位（等价于 ÷100）。

#### 步骤要点

1. `6% = 6 ÷ 100`
2. `6 ÷ 100 = 0.06`

#### 避坑思路

- 坑 1：写成 `0.6`（那是 `60%`）或写成 `6`（丢掉「百分」）
- 自检：`%` = 除以 100；`6%` 应比 `0.1` 还小

#### 答案

`0.06`

---

### 例题 2

#### 题目

把 `0.35` 化成百分数。

#### 难度

L2

#### 解题技巧

小数点右移两位，加 `%`（等价于 ×100 再加百分号）。

#### 步骤要点

1. `0.35` 小数点右移两位 → `35`
2. 加 `%` → `35%`

#### 避坑思路

- 不要写成 `0.35%`（又多加了一次百分）
- 自检：`35% = 0.35`，互化应能来回对上

#### 答案

`35%`

---

### 例题 3

#### 题目

比较 `8%` 与 `0.8` 的大小，并说明理由。

#### 难度

L3

#### 解题技巧

先统一成同一种表示（都化小数，或都化百分数），再比大小。

#### 步骤要点

1. `8% = 0.08`
2. `0.08 < 0.8`，所以 `8% < 0.8`
3. 或：`0.8 = 80%`，故 `8% < 80%`

#### 避坑思路

- 易把 `8%` 当成 `0.8`（少移一位）
- 自检：一边化完再比，禁止「看数字 8 和 0.8 凭感觉」

#### 答案

`8% < 0.8`（因为 `8% = 0.08`）

## 常见坑 / 易混

| 错法 | 正解 | 说明 |
|---|---|---|
| `6% = 0.6` | `0.06` | 少移一位 → 变成 `60%` |
| `6% = 6` | `0.06` | 丢掉「百分」 |
| `0.35 = 0.35%` | `35%` | 方向反了还叠 `%` |
