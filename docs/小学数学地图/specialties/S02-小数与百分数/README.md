# S02 小数与百分数

## 范围

**含什么：** 小数的意义与读写、小数加减乘除、百分数的意义与读写、百分数与小数互化、求一个数的百分之几、百分数应用。

**不含什么：** 分数的意义与运算（归 S03）；整数四则与运算定律（归 S01）；比、比例与正反比例（归 S05）；计量单位换算（归 S14）。
