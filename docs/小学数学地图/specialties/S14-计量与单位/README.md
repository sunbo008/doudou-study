# S14 计量与单位

## 范围

**含什么：** 长度、面积、体积 / 容积、质量、时间、人民币等常用单位及换算；单位选择的合理性与同类量统一。

**不含什么：** 图形周长、面积、体积公式本身（归 S07、S08）；速度、密度等复合单位应用题（归 S09）；负数与温度读数（归 S12）。
