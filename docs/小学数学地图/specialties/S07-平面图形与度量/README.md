# S07 平面图形与度量

## 范围

**含什么：** 角的认识与度量、长方形与正方形周长面积、三角形与平行四边形面积、圆的周长与面积、轴对称、平移与旋转（平面内）。

**不含什么：** 立体图形表面积与体积（归 S08）；长度等单位换算（归 S14）；位置与方向、数对（归 S13）；比与比例尺计算（归 S05）。
