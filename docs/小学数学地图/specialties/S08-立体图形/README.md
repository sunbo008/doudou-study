# S08 立体图形

## 范围

**含什么：** 长方体与正方体的认识、表面积与体积、圆柱与圆锥的认识、圆柱表面积与体积、圆锥体积（及组合体）。

**不含什么：** 平面图形周长面积（归 S07）；单位换算规则（归 S14，此处仅使用换算结果）；复杂展开图推理超出课标部分。
