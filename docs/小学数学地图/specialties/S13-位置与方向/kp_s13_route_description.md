# 路线描述

## 一句话

描述路线要按行走顺序分段写清每段的起点、方向、角度和距离；返程需“分段逆序+每段方向取反”。

## 典型题型（按难度）

| 难度 | 题型描述 | 状态 |
|---|---|---|
| L1 | 描述单段路线 | 已写 |
| L2 | 按顺序描述多段路线 | 已写 |
| L3 | 把去程改写为返程 | 已写 |
| L4 | 利用位移抵消重构等价路线 | 已写 |

## 例题

### 例题 1

#### 题目

小丽从家出发，向正东走 `500` 米到达书店。用一句完整的话描述路线。

#### 难度

L1

#### 解题技巧

套用“从哪里出发→向什么方向→走多远→到哪里”。

#### 步骤要点

1. 起点是家，终点是书店。
2. 方向是正东，距离是 `500` 米。

#### 避坑思路

不要只写“向东走”，否则缺起终点和距离。

#### 答案

小丽从家出发，向正东走 `500` 米到达书店。

### 例题 2

#### 题目

从学校到科技馆：先向北偏东 `30°` 走 `400` 米到广场，再从广场向正东走 `300` 米到科技馆。整理成分段路线。

#### 难度

L2

#### 解题技巧

每到一个转折点，它就成为下一段的新观测点。

#### 步骤要点

1. 第一段：学校→广场，北偏东 `30°`，`400` 米。
2. 第二段：广场→科技馆，正东，`300` 米。

#### 避坑思路

第二段的观测点是广场，不能继续以学校为观测点。

#### 答案

从学校向北偏东 `30°` 走 `400` 米到广场，再向正东走 `300` 米到科技馆。

### 例题 3

#### 题目

去程是“从 A 向东偏北 `25°` 走 `2` 千米到 B，再向正北走 `1` 千米到 C”。写出从 C 原路返回 A 的路线。

#### 难度

L3

#### 解题技巧

返程先把分段顺序倒过来，再把每段方向取反，角度和距离不变。

#### 步骤要点

1. 先走 C→B：正北的反向是正南，距离 `1` 千米。
2. 再走 B→A：东偏北 `25°` 的反向是西偏南 `25°`，距离 `2` 千米。

#### 避坑思路

若只取反方向却不逆序，第一段就会从错误的起点出发。

#### 答案

从 C 向正南走 `1` 千米到 B，再向西偏南 `25°` 走 `2` 千米到 A。

### 例题 4

#### 题目

小航从营地先向正东走 `600` 米，再向正北走 `400` 米，又向正西走 `200` 米到达观察点。不重画原路，用两段最简的正方向路线描述从观察点回营地。

#### 难度

L4

#### 解题技巧

先识别同轴方向可抵消：东 `600` 米与西 `200` 米合成向东 `400` 米。

#### 步骤要点

1. 去程的净位移是向东 `400` 米、向北 `400` 米。
2. 回程的净位移取反：向南 `400` 米、向西 `400` 米。
3. 两段的先后次序可互换，终点相同。

#### 避坑思路

题目要求“最简”而非“原路返回”，所以先合并相反位移，不必照抄三段。

#### 答案

一种描述是：从观察点向正南走 `400` 米，再向正西走 `400` 米回到营地。

## 常见坑 / 易混

- 多段路线不按顺序写，或遗漏中间转折点。
- 返程只取反方向，忘了分段顺序也要倒过来。
- 把路程长度与起终点的净位移混为一谈。

## 年级与单元

- 六年级上册「位置与方向（二）」。

## 思维横向题（L4）

例题 4 把三段路线转化为东西、南北两个独立方向的净位移，是结构化简而不是繁算。
