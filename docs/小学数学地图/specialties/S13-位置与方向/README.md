# S13 位置与方向

## 范围

**含什么：** 方位认识（东、南、西、北及中间方向）、描述路线、数对表示位置、简单坐标描述（不含负数坐标深入）。

**不含什么：** 平面图形变换（归 S07）；负数坐标（归 S12）；比例尺与地图测量（归 S05）；立体空间方位。
