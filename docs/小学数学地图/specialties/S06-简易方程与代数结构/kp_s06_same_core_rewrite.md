# 变形同核后提公因式

## 一句话

两边暂时「不像」时：先提数字、对齐括号，改成同一个核，再移项提因式（W2 的下一步）。

## 典型题型（按难度）

| 难度 | 题型描述 | 状态 |
|---|---|---|
| L1 | 提数字改写一次式（找核） | 已写 |
| L2 | 已提示同核的方程 | 已写 |
| L3 | — | 待补 |
| L4 | `(9a+15)² = 10+6a` 类同核改写 | 已写 |

## 例题

### 例题 1

#### 题目

把 `9a+15` 与 `10+6a` 分别改写成「数字 ×（核）」的形式，并指出它们的核是否相同。

#### 难度

L1

#### 解题技巧

先找数字公因式，再写括号；必要时用交换律对齐项序。

#### 步骤要点

1. `9a+15 = 3(3a+5)`，核 = `3a+5`
2. `10+6a = 2(5+3a) = 2(3a+5)`，核 = `3a+5`
3. 两边核相同

#### 避坑思路

- 坑 1：只想提字母 `a`，提不出数字公因式 `3` / `2`
- 坑 3：忘记 `5+3a = 3a+5`
- 书写要求：写出「数字 × 括号」，禁止只在脑子里消

#### 答案

核都是 `3a+5`；`9a+15=3(3a+5)`，`10+6a=2(3a+5)`

---

### 例题 2

#### 题目

已知可改写成 `9u² = 2u`（其中 `u = 3a+5`），求 `u`，再求 `a`。

#### 难度

L2

#### 解题技巧

已同核则回到 W2 正路：移项提因式，注意 `u=0`。

#### 步骤要点

1. `9u² − 2u = 0` → `u(9u−2) = 0`
2. `u = 0` 或 `u = 2/9`
3. `3a+5 = 0` → `a = −5/3`；`3a+5 = 2/9` → `3a = 2/9 − 5 = 2/9 − 45/9 = −43/9` → `a = −43/27`

#### 避坑思路

- 丢掉 `u=0`
- 分数运算：通分要写清楚

#### 答案

`u=0` 或 `2/9`；`a=−5/3` 或 `a=−43/27`

## 思维横向题（L4）

### 例题 L4（主维护处）

#### 题目

解方程：`(9a+15)² = 10+6a`

#### 难度

L4

#### 表面像什么 → 实际要先看出什么

- **表面**：左边是整式平方，右边是一次式，像要硬展开或两边开方。
- **实际**：两边都含核 `3a+5`；先改写成同核，再按 W2 移项提因式。

#### 主专项 + 横向标签

- 主专项：S06
- 横向标签：同核改写、提公因式、思维横向

#### 解题技巧

口令：**先提数字 → 再对齐括号 → 再移项提因式。**  
可设 `u = 3a+5` 降复杂度。

#### 步骤要点

1. 左边：`9a+15 = 3(3a+5)` → `[3(3a+5)]² = 9(3a+5)²`
2. 右边：`10+6a = 2(3a+5)`
3. 方程：`9(3a+5)² = 2(3a+5)`；设 `u=3a+5` → `9u² = 2u`
4. `9u² − 2u = 0` → `u(9u−2)=0` → `u=0` 或 `u=2/9`
5. `a=−5/3` 或 `a=−43/27`；代回原式验根

不设 `u` 也可：`9(3a+5)² − 2(3a+5) = 0` → `(3a+5)[9(3a+5)−2]=0`。

#### 避坑思路

- 坑 2：硬展开左边成长多项式，易算错
- 坑 1：不提数字，看不出同核
- 丢掉 `u=0` 对应的解
- 自检：两解都代回原式

#### 答案

`a = -\dfrac{5}{3}` 或 `a = -\dfrac{43}{27}`（均须验根）

[`practice/W2b-变形提公因式/`](../../../../practice/W2b-变形提公因式/)

#### 易混点

会做 `(a−5)² = a−5`（已同构），却不会「先变形创造同核」。

## 常见坑 / 易混

| 坑 | 表现 | 对策 |
|---|---|---|
| 1 | 只看字母不提数字 | 先找数字公因式 |
| 2 | 硬展开左边 | 优先同核改写 |
| 3 | 交换律对不齐 | `5+3a` 写成 `3a+5` |
| — | 丢 `u=0` | 积为零两解都写 |
