# 同核心算式的整体改写

## 一句话

算式中反复出现同一个数或同一个括号时，把它看成一个整体，先用交换律对齐，再逆用乘法分配律合并。

## 典型题型（按难度）

| 难度 | 题型描述 | 状态 |
|---|---|---|
| L1 | 两项含同一个乘数的简算 | 已写 |
| L2 | 两项含同一个方框数，合并后求值 | 已写 |
| L3 | 两项含同一个括号整体，逐层还原方框数 | 已写 |
| L4 | 先用交换律对齐括号，再整体合并 | 已写 |

## 例题

### 例题 1

#### 题目

简便计算：`36×25+64×25`。

#### 难度

L1

#### 解题技巧

两项都乘 `25`，把 `25` 看成共同核心，逆用乘法分配律。

#### 步骤要点

1. 找到共同核心 `25`。
2. `36×25+64×25=(36+64)×25`。
3. `100×25=2500`。

#### 避坑思路

- 只能合并共同乘数相同的两项。
- 括号里是 `36+64`，不能把两个数相乘。

#### 答案

`2500`

---

### 例题 2

#### 题目

同一个方框表示同一个数。已知 `7×□+3×□=120`，求方框里的数。

#### 难度

L2

#### 解题技巧

把 `□` 看成共同核心，先合并成 `10×□`，再用乘除互逆求方框数。

#### 步骤要点

1. `7×□+3×□=(7+3)×□`。
2. 得到 `10×□=120`。
3. `□=120÷10=12`。
4. 验算：`7×12+3×12=84+36=120`。

#### 避坑思路

- 两个方框必须代表同一个数，才能合并。
- 求出结果后代回原算式验算，不能只验合并后的算式。

#### 答案

`□=12`

---

### 例题 3

#### 题目

同一个方框表示同一个数。已知 `4×(□+5)+6×(□+5)=150`，求方框里的数。

#### 难度

L3

#### 解题技巧

把整个 `(□+5)` 看成共同核心。先合并外面的倍数，再从外向内逐层还原。

#### 步骤要点

1. `4×(□+5)+6×(□+5)=(4+6)×(□+5)`。
2. 得到 `10×(□+5)=150`。
3. `□+5=150÷10=15`。
4. `□=15-5=10`。
5. 验算：`4×15+6×15=60+90=150`。

#### 避坑思路

- 共同核心是完整括号 `(□+5)`，不能只看方框。
- 先求括号整体等于多少，再减 `5`，顺序不能倒。

#### 答案

`□=10`

---

### 例题 4

#### 题目

同一个方框表示同一个数。已知 `24×(□+3)+16×(3+□)=800`，求方框里的数。

#### 难度

L4

#### 解题技巧

两组括号顺序不同。先用加法交换律确认 `3+□=□+3`，把它们对齐成同一个核心，再整体合并。

#### 步骤要点

1. `3+□=□+3`，所以原式可写成 `24×(□+3)+16×(□+3)=800`。
2. 逆用乘法分配律：`(24+16)×(□+3)=800`。
3. `40×(□+3)=800`，所以 `□+3=800÷40=20`。
4. `□=20-3=17`。
5. 验算：`24×20+16×20=480+320=800`。

#### 避坑思路

- `□+3` 与 `3+□` 因加法交换律相等；若括号里是减法，不能照搬。
- 合并的是外面的 `24` 与 `16`，括号整体只保留一份。

#### 答案

`□=17`

## 常见坑 / 易混

| 表现 | 原因 | 对策 |
|---|---|---|
| 看见方框就分别计算 | 没把相同部分视为整体 | 圈出每项完全相同的核心 |
| 把 `(□+5)` 拆散 | 共同部分识别不完整 | 括号连同内部符号一起保留 |
| 把 `□-3` 与 `3-□` 当相同 | 误用交换律 | 只在加法顺序互换时对齐 |
| 算完不验 | 中途还原可能出错 | 把方框数代回最初算式 |

## 思维横向题（L4）

L4 的关键不是扩大运算范围，而是先识别 `□+3` 与 `3+□` 表示同一个整体，再完成小学范围内的简算和逆向求值。
