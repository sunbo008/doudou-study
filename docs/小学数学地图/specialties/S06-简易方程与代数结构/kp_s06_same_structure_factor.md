# 同构方程移项提公因式

## 一句话

两边已经是同一个「核」时：移项 → 提公因式 → 积为零；不要两边同除含未知数的式子。

## 典型题型（按难度）

| 难度 | 题型描述 | 状态 |
|---|---|---|
| L1 | 数字桥：`(□)² ÷ □ = □` | 已写 |
| L2 | `(a−5)² = a−5` 移项提因式 | 已写 |
| L3 | 对比「两边同除」为何丢解 | 已写 |
| L4 | 两边核不同、需先改写 | 见 [`kp_s06_same_core_rewrite`](./kp_s06_same_core_rewrite.md) |

## 例题

### 例题 1

#### 题目

不查计算器，说明为什么 `3² ÷ 3 = 3`，并类比到 `(a−5)² ÷ (a−5)`（在 `a−5 ≠ 0` 时）等于什么。

#### 难度

L1

#### 解题技巧

先写成乘法再约分：`(□)² = □·□`，再除以 `□`。

#### 步骤要点

1. `3² ÷ 3 = (3·3) ÷ 3 = 3`
2. `(a−5)² ÷ (a−5) = (a−5)·(a−5) ÷ (a−5) = a−5`（要求 `a−5 ≠ 0`）

#### 避坑思路

- 禁止在脑子里「凭感觉消掉」
- 必须写开平方再约

#### 答案

规则：`(□)² ÷ □ = □`（`□ ≠ 0`）；故在 `a≠5` 时等于 `a−5`

---

### 例题 2

#### 题目

解方程：`(a−5)² = a−5`

#### 难度

L2

#### 解题技巧

正路四步：移到一边 → 提公因式 → 积为零 → 写解并验根。  
优先移项因式分解，不优先两边同除。

#### 步骤要点

1. `(a−5)² − (a−5) = 0`
2. `(a−5)[(a−5) − 1] = 0` → `(a−5)(a−6) = 0`
3. `a−5 = 0` 或 `a−6 = 0` → `a = 5` 或 `a = 6`
4. 验根：`a=5` → `0=0`；`a=6` → `1=1`，都成立

换元：设 `x = a−5`，则 `x² = x` → `x(x−1)=0` → 同上。

#### 避坑思路

- 坑 8：提公因式后第二括号应是 `a−5−1`，不是再写一个 `a−5`
- 坑 3：只写一解不完整
- 不必硬展开成 `a²−10a+25`

#### 答案

`a = 5` 或 `a = 6`

### 例题 3

#### 题目

若对 `(a−5)² = a−5` 两边同除 `a−5`，会得到什么？少了哪个解？为什么？

#### 难度

L3

#### 解题技巧

比较「同除路径」与「移项路径」；凡除过含未知数的式子，必须补查除数为 0 的情形。

#### 步骤要点

1. 同除（且默认 `a≠5`）得 `a−5 = 1` → `a = 6`
2. 但 `a = 5` 代入原式成立，却被当作除数丢掉
3. 结论：含未知数的式子不能随便拿到两边去除

#### 避坑思路

- 坑 1（核心）：两边同除丢解
- 补救：若已同除，必须单独检查 `a−5 = 0` 是否也是解
- 正路仍是移项提因式

#### 答案

同除只得 `a=6`，丢掉 `a=5`；因为除数不能为 0，却恰好漏掉了这个解

## 常见坑 / 易混

- 两边同除含未知数式子 → 丢 `□=0` 解
- 约分不写开 → 卡在「平方除以底」
- `□² = □` 通常两解：`□=0` 或 `□=1`
