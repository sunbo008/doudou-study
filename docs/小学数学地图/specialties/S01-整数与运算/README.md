# S01 整数与运算

## 范围

**含什么：** 认数（万以内、亿以内）、整数四则运算、四则混合运算、运算估算、速算技巧、运算定律（交换律、结合律、分配律等）。运算估算在本专项；与 S11 的规律 / 数感情境下的合理猜测区分。

**不含什么：** 小数、分数、百分数的意义与运算（归 S02、S03）；因数倍数与整除（归 S04）；简易方程与字母表示（归 S06）；应用题数量关系建模（归 S09）；规律 / 数感类合理猜测（归 S11）。
