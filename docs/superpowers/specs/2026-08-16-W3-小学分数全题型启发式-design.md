## 原则

1. `00-分数意义底层逻辑.md` 只讲概念，禁止算式与例题。
2. 练习卷不提前点破通项/选型口诀；由易到难垫脚。
3. 等比半加链只是加减结构压轴之一，不得成为唯一终点。
4. `学后总结-技巧与避坑.md` 须全部练习完成后再发。
5. `覆盖清单.md` 为验收唯一标准：每条题型至少 1 题可追溯。

## 结构

- 册1 认识与意义（初步认识 + 意义性质）
- 册2 约分通分与加减（含剩余、相邻差、短链→结构加减）
- 册3 乘法（意义、计算、混合、应用）
- 册4 除法（意义、计算、应用）
- 总复习卷（选型综合）
- 学后总结

## 使用顺序

逻辑文 → 册1 三卷 → 册2 三卷 → 册3 三卷 → 册4 三卷 → 总复习 → 学后总结。
