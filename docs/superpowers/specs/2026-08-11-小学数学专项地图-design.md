# 小学数学专项地图设计规格

| 项目 | 内容 |
|---|---|
| 状态 | 已批准 |
| 日期 | 2026-08-11 |
| 学生 | 豆豆（人教版六年级上册） |
| 仓库 | doudou-study |
| 第一期目标 | 建立 1～6 年级双视图知识点地图骨架，并产出含 L4 的厚实样板 |

## 1. 背景与目标

现有材料以分班备考弱项为主（`practice/W1`、`W2`、`W2b`），缺少覆盖小学全程的能力向总表。本规格定义「小学数学专项地图」：先建可检索、可扩展的知识点体系，再按需开练习包。

**成功标准（第一期）：**

- 能按「专项」与「年级」两种视图浏览小学数学知识点；
- 每个知识点有统一模板；例题带 L1～L4 难度，其中 L4 为思维横向题；
- 每道例题都写清**解题技巧**与**避坑思路**（可与现有「技巧与避坑」讲义同风格）；
- 现有 W1 / W2 / W2b 能在地图中定位并回链；
- 命名与目录约定明确，后续可按专项增量填厚，无需推翻结构。

**非目标（本规格不包含）：**

- 一次性写完全部知识点的厚实正文；
- 为全部专项批量生成练习卷；
- 改造 AI 答辩式学习系统本身。

## 2. 范围与约束

| 维度 | 决定 |
|---|---|
| 产物类型 | 知识点总表 / 专项地图（非全量题库、非全量练习包） |
| 年级覆盖 | 一年级～六年级全覆盖（分期填厚） |
| 主分类 | 专项为主索引；年级 / 单元为副视图标签 |
| 教材对齐 | 人教版；六年级上册以手边实书为准；一～五年级按人教版先建，单元名允许日后微调 |
| 条目深度 | 厚实：例题（含解题技巧与避坑思路）、易混对比、练习与弱项关联；并含难度分级与 L4 横向题 |
| 落地结构 | `docs/小学数学地图/` 专项文件夹地图；`practice/` 仅保留已开练专项 |

```text

└── specialties/

    ├── S02-小数与百分数/
```

约定：

- 知识点正文只写在 `specialties/Sxx-*/kp_*.md`；
- `专项索引.md`、`年级索引.md` 只做导航与聚合，不复制厚实正文；
- `practice/W*` 继续存放讲义与练习卷；地图通过 frontmatter 的 `practice` / `weak_ref` 回链。

## 5. 知识点条目模板

### 5.1 命名

- 文件：`kp_s{专项两位}_{英文短名}.md`
- 例：`kp_s02_decimal_div_percent.md`、`kp_s06_same_core_rewrite.md`
- `kp_id` 与文件名主干一致；发布后禁止改字符串；废弃用 `status: deprecated`

### 5.2 Frontmatter

```yaml
kp_id: kp_s02_decimal_div_percent
title: 小数除以百分数
specialty_id: S02
grades: [5, 6]
pep_units:
  - { grade: 6, volume: 上, unit: "百分数（一）" }
status: active   # active | draft | deprecated
practice: practice/W1-小数乘除/   # 无则省略或留空
weak_ref: W1                     # 无则省略
lateral_tags: []                 # L4 横向标签，如 [同核改写, 提公因式]
```

### 5.3 正文结构

1. **一句话**：该知识点要会什么  
2. **典型题型（按难度）**：表格，含 L1～L4（缺档标「待补」）  
3. **例题**：至少覆盖已列出的难度档；**每道例题强制含下列子块**  
4. **常见坑 / 易混**（知识点级汇总，可与例题避坑互相引用，避免只写空泛列表）  
5. **年级与单元**（与 `pep_units` 一致，可补充说明）  
6. **思维横向题（L4）**：可跨专项；见下节  
7. **关联**：相近知识点、练习材料、素质跟踪弱项  

每个知识点至少具备 **L1 + L2**；L3 / L4 能写则写，否则显式「待补」。

### 5.4 单道例题强制子块

每道例题（含 L1～L4）按同一结构书写：

| 子块 | 要求 |
|---|---|
| 题目 | 完整题干 |
| 难度 | L1 / L2 / L3 / L4 |
| 解题技巧 | 可复用的方法口诀或决策顺序（先看什么、再改写什么、最后算什么） |
| 步骤要点 | 关键演算步骤（不必逐步展开到竖式细节，除非该坑就在定位/位数） |
| 避坑思路 | 本题最容易错在哪、如何自检；可点名「坑 n」若已有讲义编号 |
| 答案 | 最终结果（多解须列全并说明验根） |

风格对齐现有讲义：`小数乘除法技巧与避坑`、`代数方程变形技巧与避坑`、`变形提公因式技巧与避坑`——**技巧可迁移，避坑要针对本题**，禁止只写「细心一点」。

## 6. 难度与思维横向题

| 级别 | 名称 | 定义 |
|---|---|---|
| L1 | 基础 | 课内原题套路，步骤单一 |
| L2 | 熟练 | 条件变形或多一步转化 |
| L3 | 综合 | 两知识点组合或易混陷阱 |
| L4 | 思维横向 | 须先识别结构 / 改写再运算，而非套公式直算 |

**L4 书写强制字段：**

- 题目原文（如 `(9a+15)² = 10 + 6a`，求 `a`）  
- 主专项 + 横向标签  
- 「表面像什么 → 实际要先看出什么」  
- **解题技巧**（结构识别 / 同核改写等可复用套路）  
- **步骤要点** + **避坑思路**（与 §5.4 相同，不可省略）  
- 关联练习（若有）  
- 易混点  

跨专项的 L4：**正文只维护一处**，其他知识点用链接引用，避免双份漂移。偏初一衔接的变形技巧默认归 **S06**，并打横向标签。

## 7. 双视图

- **专项索引**：主入口；按 S01～S14 列出知识点链接、弱项与练习回链、L4 数量概览  
- **年级索引**：按年级 → 上下册 → 单元列出同一批 `kp_*.md` 链接  
- 两视图数据源相同；禁止在索引中维护第二份例题正文

## 9. 分期计划

### 一期（本规格后的首个实现计划）

- 创建目录、README、命名规范、人教版对齐说明  
- 写好专项索引与年级索引骨架  
- 14 个专项 README（范围边界）  
- 各专项知识点**清单级**占位（标题 + 年级标签即可）  
- **厚实样板 3～5 个 kp**，优先覆盖 W1 / W2 / W2b，且至少 1 个完整 L4（含 `(9a+15)² = 10+6a` 类）；样板例题均含解题技巧与避坑思路  

**一期验收：** 双视图可浏览；W 系列可定位；模板可复制；命名无冲突；厚实样板中每道例题具备「技巧 + 避坑」。

### 二期

- 按人教六上实书逐单元填厚  
- 补六下与分班高频（分数、比例、圆、方程等）  
- 各专项补充 L4 横向题  

### 三期

- 一～五年级回填  
- 对照实书微调 `pep_units`  
- 查漏补 L3 / L4  

## 10. 风险与原则

- **体量风险**：全量厚实不可一期完成 → 用分期与「待补」显式管理  
- **单元名漂移**：1～5 年级单元名以「可后调」为前提，不阻塞骨架  
- **YAGNI**：不引入题库数据库、自动出卷脚本、SSMEP 中学 taxonomy 工具链，除非后续单独规格  
- **稳定 ID**：`Sxx` 与 `kp_id` 不因标题润色而改名  

## 11. 已确认决策摘要

1. 先做地图，不做全量练习包  
2. 1～6 年级全覆盖，分期填厚  
3. 双视图：专项主、年级副  
4. 教材：人教版；六上严对齐；1～5 可后调单元名  
5. 厚实条目 + L1～L4；L4 为思维横向题  
6. 每道例题强制含解题技巧与避坑思路（对齐现有「技巧与避坑」讲义风格）  
7. 目录采用 `docs/小学数学地图/` 专项文件夹方案  
8. 专项共 14 类（含位置与方向、计量与单位）
