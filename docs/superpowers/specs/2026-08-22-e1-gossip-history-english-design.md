# E1 · 野史英语（纠错钩子 × 课纲对齐）· 设计

| 项目 | 内容 |
|---|---|
| 日期 | 2026-08-22 |
| 学生 | 豆豆 · 初一分班备考 |
| 主攻能力 | 英语输出（写作/翻译）+ 听说 |
| 历史范围 | 统编版初中历史 · 七年级上册（夏商周 → 三国两晋南北朝） |
| 每日时长 | 30～40 分钟（与数学 W 系列并行） |
| 材料路径 | `practice/E1-野史英语/` |

## 一、核心思路

用 **纠错钩子** 讲英文野史八卦，把 **统编版七上** 每一课变成预习钩子；正史锚点（年份、人物、事件、意义）必须准确，课上理解更快。

> 每一集野史 = 课本某一「课」的预习钩子，不是随机娱乐。

## 二、红线约束

### 2.1 史实

1. **时代不能错**：如商鞅属战国·**秦国**，不是 **秦朝**；不能与秦始皇同时代叙述。
2. **人物关系不能张冠李戴**：不能把 A 的事迹安到 B 身上。
3. **年份、事件、意义** 必须与课本 Fact Box 一致；野史只负责叙事张力，不改硬核事实。

### 2.2 人物命名

**姓名不能丢；emperor / king / ruler / duke 等称号词要学，且应与姓名同现——称号不能代替姓名。**

| 禁止 | 推荐 |
|---|---|
| *the Duke told Shang Yang…*（不知 Duke 是谁） | * **Qin Xiaogong (秦孝公)**, the **ruler** of Qin, told **Shang Yang (商鞅)**…* |
| *The Emperor unified China.*（未说是谁） | * **Ying Zheng (嬴政)** became China's first **emperor**.* |

**首次出现**：`English Name (中文名)`，可加称号：*Qin Xiaogong (秦孝公), the ruler of Qin*。

**智慧原则**：称号词 **主句反复出现**；**he/she 尽量在从句中**；秦孝公用 **ruler**，**emperor** 留给 **Ying Zheng (嬴政)**。

### 2.3 野史尺度

- **拉兴趣期** 野史:正史 = **9:1** —— 可夸张、可悬念，但不编造课纲未涉及且易混淆的「事实」。
- **固化期 / 考前** 野史:正史 = **7:3** —— 缩短八卦，加长 Fact Box 输出。

### 2.4 词汇（强制）

**正文尽量只用当下已学单词** —— 读野史 = 复习旧词。默认词池：**人教版小学英语 3～6 年级**（以豆豆已学完册次为准，当前按六下及以前计）。

| 原则 | 说明 |
|---|---|
| 优先已学词 | 能写 *change the laws* 就不写 *reform* |
| 专有名词例外 | 人名、地名、年份不算超纲 |
| 超纲必附表 | 正文若必须用词池外词，在短文后附 **「超纲词复习」** 表 |
| 数量上限 | 每集超纲词/短语 **≤ 8 个**；多了就改正文 |

超纲表格式：`单词 | 音标(可选) | 中文 | 文中例句`。详见 `practice/E1-野史英语/词汇规范.md`。

可选 **「本集复习词」**：标出正文刻意复现的已学高频词，读前 2 分钟口头复习。

## 三、纠错钩子四步模板

每集 Gossip Hook 固定结构：

```
① 抛误区（15 秒）—— 一个听起来合理的错误判断
② 打脸（10 秒）—— WRONG! Big mistake!
③ 野史展开（3～5 分钟）—— 全程用真实姓名
④ 正史收网（30 秒）—— REAL history: 年份 + 人物 + 意义
```

## 四、Episode 结构（双文件）

| 文件 | 读者 | 内容 |
|---|---|---|
| **AI脚本**（**单文件给 AI**） | 内嵌 `# SYSTEM` + `# SCRIPT`；[READ]/[ASK] 锁、问题链、纠偏口令 |
| **小朋友版** | 豆豆 | 英文故事、**读完回答**（无答案）、复习词/超纲词、落笔三句 |

| 块 | 所在文件 |
|---|---|
| 纠错钩子正文 | 两文件均有（小朋友版无元数据） |
| **问题链 Q0–Q6 + 落笔 W1–W2** | **仅 AI脚本** |
| **读完回答（问题列表）** | **仅小朋友版** |
| Fact Box / 正史卡 | AI脚本裁决用；小朋友版简表 |

## 五、三阶段与切换

| 阶段 | 野史:正史 | 进入 | 退出 |
|---|---|---|---|
| 拉兴趣期 | 9:1 | 开始 E1 | 完成 **8 集** 或 **14 天**（先到为准） |
| 固化期 | 7:3 | 拉兴趣期结束 | 分班考 **前 7 天** |
| 考前收紧 | 7:3，停新八卦 | 考前 7 天 | 考试结束 |

**拉兴趣 → 固化** 额外条件：连续 **3 集** 无提示英文写出 Fact Box 至少 **2 条** 正史锚点。

## 六、每日流程（30～40 min）

| 步骤 | 时间 | 能力 |
|---|---|---|
| 扫本集复习词 | 2 min | 复习已学词 |
| AI 朗读 / 自读小朋友版 | 6 min | 听 + 读 |
| 攻超纲词表 | 3 min | 读 + 跟读例句 |
| **AI 问题链 Q0–Q6**（一次一题） | 8 min | 说 |
| 填写正史卡 | 5 min | 写 |
| 落笔三句 | 7 min | 写/译 |
| 核验课本 + 存档 | 4 min | 历史 |

D7、D14 为复测日：滚动正史卡 + 闭卷写 3 句，不做新 Episode。

## 八、与现有系统对接

- **AI 答辩式**：家长只发 **一个** `EYY-AI脚本.md`；文件内 `# SYSTEM` 为约束，`# SCRIPT` 为正文；禁止中文扩写故事。
- **素质跟踪**：在 `docs/素质跟踪/豆豆/素质跟踪报告.md` 登记弱项 **E1**。
- **升级标准**：连续 3 集 —— ① 90 秒口述过关 ② 闭卷写 3 句 ③ Fact Box 2 条正确且 **人名无泛称**。

## 九、验收

1. 每集 Fact Box 与统编版七上对应课一致（家长/课本核验）。
2. 每集含 **AI脚本**（问题链 + 标准答案）与 **小朋友版**（听完回答，无答案）；脚本经 **命名规范 N1–N8** 通过。
3. 落笔三句能在无 AI 条件下独立完成。
4. 每集有 **超纲词复习** 表；正文超纲词 ≤ 8 且全部收录。
