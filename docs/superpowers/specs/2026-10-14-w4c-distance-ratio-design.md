## 一、目标与非目标

### 1.1 目标

1. 能把「到 A、到 B 的距离关系」写成带绝对值的方程。
2. 理解 `|左| = k|右|` 为何拆成 `左 = ±k·右`（几何 / 模相等，白话讲解）。
3. 解出所有候选 `P`，验根后留下真解；会算每个真解对应的 `n = PA+PB`。
4. 心算能稳定处理 `mx+a=nx−b` 及带括号变体（见第四节）。
5. 面对花样条件（倍、比、多/少、几倍多/少、分数小数坐标）不慌列式。
6. 应用题能自己把情境抽象成数轴距离关系再列式（每天练 2 题）。

### 1.2 非目标

- 不讲折反射求折点（仍归 W4 混编）。
- 不讲绝对值不等式。
- 不把「隐藏考点」写进学生教学页或口诀（见第六节：只出题，不剧透）。
- 应用题**要出**（温度、行程、海拔等均可），用来考真实理解力；不是整卷主线，**每天固定 2 题**（见第七节）。其余题默认数轴 + 字母点。

## 三、教学页设计（`00-几何与±法则.md`）

语言要求：给人讲的话；短句；少定义腔；考虑初一接受度。禁止堆砌「换言之 / 需要注意的是 / 综上所述」。

### 3.1 必讲块（按顺序）

1. **距离与绝对值**  
   数轴上两点中间「隔了几格」叫距离；用绝对值写出：  
   `PA = |P−A|`，`PB = |P−B|`。  
   （只讲「怎么写」；不把「为负则舍」写成应试提醒——该类坑见第六节，只出题不剧透。）

2. **题目在问什么**  
   `PB = 2·PA` → 人话：`P` 到 `B` 的距离，是到 `A` 的 2 倍。  
   写成：`|P−B| = 2|P−A|`。

3. **几何直观（k=1 与 k=2）**  
   - `k=1`：等距 → 中点（可点出已做过的题）。  
   - `k=2`：一般有两个位置（外侧一个、A/B 之间靠 A 侧一个），用数轴草图标两解；不引入「外分点」术语。

4. **为何 `左 = ±k·右`（合理性）**  
   两个数绝对值一样大 → 要么本身相等，要么差一个负号。  
   故 `|P−B| = k|P−A|` 对应：  
   `P−B = k(P−A)` 或 `P−B = −k(P−A)`。  
   两式都解，再代回原绝对值方程验。

5. **与「分区」的关系**  
   口诀仍对齐 W4：`分区 → 去绝对值 → 验根`。  
   本专项默认路径：**± 两式 + 必验**（贴考卷「先列方程再解并验」）。

6. **求 `n`**  
   每个留下的 `P`：`n = |P−A| + |P−B|`（先绝对值再相加）。

7. **条件怎么写方程（只教「会写」，不教坑名）**  

   | 人话 | 方程骨架 |
   |---|---|
   | 几倍 | `PB = k·PA` |
   | 等距 | `PA = PB` |
   | 比 `PA:PB = m:n` | `n·PA = m·PB` |
   | 多 / 少多少 | `PB = PA ± d` |
   | 几倍多 / 少多少 | `PB = k·PA ± d` |

   强调：先把人话写成带 `|P−A|`、`|P−B|` 的式子，再展开。  
   **不写**「右边变负就无解」「距离不能为负」等剧透句（见第六节）。

8. **心算衔接**  
   去括号后常变成 `mx + a = nx − b` 一类。  
   口诀：有括号先打开；打开后含 x 一边、常数一边；再除。

### 3.2 教学页明确不写的内容

- 隐藏考点 1～8 的名称、口诀、防坑表。  
- 「倍少多少时先看右边是不是正的」一类提醒。  
- 完整「无解判定定理」。

## 四、心算形态（尽量丰富）

从简到繁，Day1 打底、Day2 加难：

| 档 | 形态 |
|---|---|
| ① | `mx + a = nx − b` |
| ② | `m(x + a) = nx − b` |
| ③ | `mx + a = n(x − b)` |
| ④ | `m(x + a) = n(x − b)` |
| ⑤ | `m(m′x + a) = n(x − b)` 或 `m(x + a) = n(n′x − b)` |

可含负系数、分数系数（Day2）。  
距离比展开后常见 ③（含负号的 `−k(P−A)`）；②④⑤ 为专项加练，避免展开卡壳。

## 五、距离题花样（两天都要「花样」，Day2 更满）

| 类 | 说明 |
|---|---|
| 整倍 / 换边倍 | `PB=k·PA`，`PA=k·PB` |
| 等距 | `PA=PB` |
| 分数倍 | 如 `(1/2)`、`(3/2)` |
| 整数 / 分数 / 小数坐标 | A、B 不限于整数 |
| 多多少 / 少多少 | 无倍，加减 |
| 几倍多多少 / 几倍少多少 | `k·PA ± d`；可换边 |
| 比 | `PA:PB = m:n` |
| 纯 x | `|x−a|=k|x−b|` |
| 求 `n` / 比较两解的 `n` | Day1 多数带 `n`；Day2 可问谁大、差多少 |
| 应用题 | 每天 2 题；情境可温度、行程、海拔、座位号等；先抽象成数轴上两点距离关系，再列式 |

应用题要求：

- 题干用人话给「倍 / 比 / 多多少 / 几倍多少」等关系，**不直接写出** `|P−A|`。
- 学生须自己设点、列绝对值方程（或等价距离式），再求点 / 求 `n`。
- Day1：情境简单、对应整倍或等距（可带求 `n`）。
- Day2：**两道应用取 B 档**——一道对齐题 7/8 难度（「几倍还少」、右边可负 / 分段舍假根；现为登山题 19），另一道保持偏易（现为座位「多多少」题 20）。可另埋 H5/H6。
- 可与隐藏考点叠加，但每天 2 题额度固定，不挤占成题海。

## 六、隐藏考点（学生卷不剧透；答案可注）

全部纳入出题；教学页与学生口诀**不出现**下列名称。家长 `答案.md` 可一行注明舍因，供批改。

| 编号 | 隐藏点 | 埋法 |
|---|---|---|
| H1 | 增根：线性式对、原绝对值式不对 | 改错 + 双解验根题（类 Day02 之 `P=5`） |
| H2 | 漏解：只做 + 支，或丢掉分数解 | 要求「所有 P」；答案含分数解 |
| H3 | `n` 用带符号差相加 | 求 `n` 题；错法在答案旁注 |
| H4 | `n < \|A−B\|`（不可能） | 设一假根或验算步骤让其别扭 |
| H5 | 倍+多/少却死套纯倍 ± | 题干用「2 倍还多/少」；列式对错靠自检 |
| H6 | 比与倍列反 | `PA:PB=m:n` 与换边倍混排 |
| H7 | 「最多几个 / 实际几个」一律答 2、2 | 埋 0 解或 1 解题 |
| H8 | 边界：`P` 在 A 或 B 上 | Day2 夹一题；验根自然淘汰或保留 |

特别约定（用户定稿）：

- **「几倍少多少 → 右边变负 / 长度不合理」**：**必出题，不讲解、不口诀**。  
- 学生侧只要求：列式、求解、验根。  
- 即使某步「等式好像对了」，若导致距离意义下不合理，应在验根时自己划掉——当作隐藏考点，不预告。

## 七、两日卷面结构

### 7.1 Day01（约 20 题，25～30 分钟）

| 块 | 题量（约） | 内容 |
|---|---|---|
| A 心算 | 8 | ①②③ 为主，④ 少量；含 1～2 道「像距离展开」的式子 |
| B 列式 | 3 | 只写绝对值方程与 ±（或加减）展开，可不算完 |
| C 求 P / n | 6～7 | 整倍、等距、换边；分数/小数坐标；多/少或几倍多/少；多数带 `n` |
| D 应用 | **2** | 情境题 → 自设点列式；对应整倍或等距为主 |
| E 短答 | 1 | 为何写两式 / 验根看什么（不涉及 H 剧透） |

过关：≥15/20；必对：心算 ≥6/8；至少一道双解距离比 + 对应两个 `n`；应用 2 题至少对 1。

隐藏考点：H1、H2、H3 轻埋；「几倍少多少」至少 1 道（可废根，不剧透）。

### 7.2 Day02（约 20 题，30～35 分钟）

| 块 | 题量（约） | 内容 |
|---|---|---|
| A 心算加难 | 5～6 | ④⑤、负号、分数系数 |
| B 加难距离 | 7～8 | 分数倍、比、几倍多/少×2～3、小数/分数坐标、纯 x、双解两 `n` |
