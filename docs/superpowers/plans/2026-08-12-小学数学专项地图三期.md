# 小学数学专项地图三期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在二期校验契约上完成一至五年级细知识点回填、公开教材目录核验和全地图验收。

**Architecture:** 沿用二期的单文件细知识点、双视图和只读校验器。一至五年级目录证据先写入教材基线并标 `verified_public`；知识正文按年级批次交付，但仍按 S01～S14 主专项存放。

**Tech Stack:** Markdown、Python 3 标准库 `unittest`、权威公开教材页面、Git。

## Global Constraints

- 必须在二期全量校验通过后执行本计划。
- 一至五年级只能使用人民教育出版社、教育行政部门或教材实物目录等权威来源；搜索摘要不能单独作为证据。
- 未与用户手边实书核对的条目统一使用 `source_verification: verified_public`，不得写成 `verified_book`。
- 一个 `kp_*.md` 只承载一个独立能力；active 至少有 L1、L2；核心知识补 L3、L4。
- 低年级不适合 L4 时，必须给出适龄原因和横向能力链接，不生造超纲竞赛题。
- 不复制教材原文或整页习题，不引入数据库或第三方依赖。
- 规格：`docs/superpowers/specs/2026-08-12-小学数学专项地图二三期-design.md`。
