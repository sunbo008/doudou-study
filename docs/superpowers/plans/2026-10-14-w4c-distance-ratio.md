```markdown
# 距离比：几何与 ± 两式

给数轴上的点 A、B，找点 P，并会算 n = PA + PB。

## 1. 距离怎么写

数轴上两个点，中间隔了几格，叫距离。
P 到 A 的距离写成：PA = |P − A|
P 到 B 的距离写成：PB = |P − B|
绝对值的意思：不管谁大谁小，只留「隔了几格」。

## 2. 题目在说什么

若题目写 PB = 2 · PA，用人话就是：
P 到 B 隔的格数，是 P 到 A 隔的格数的 2 倍。
写成数学式：|P − B| = 2|P − A|
（k 是几，就是几倍。）

## 3. 数轴上看看（k=1 和 k=2）

- PA = PB（一倍，等距）：P 在 A、B 正中间。
- PB = 2 · PA：一般能找到两个位置——一个在外侧较远，一个在 A、B 之间更靠 A。
（自己在纸上画 A、B，把两个 P 标出来；不要死记名字。）

## 4. 为什么要写两式：左 = ±k·右

两个数，绝对值一样大，只有两种可能：
1. 两个数本身相等；
2. 差一个负号（一正一负，去掉符号后一样大）。

所以 |P − B| = k|P − A| 时，写成：
- P − B = k(P − A)
- P − B = −k(P − A)

两式都解一遍。解出来的每个 P，都要代回 |P − B| 和 k|P − A| 看是否相等。相等才留。

## 5. 和口诀「分区 → 去绝对值 → 验根」

本专项默认：先写 ± 两式，解完必验根。
（分区是另一条路：先看 P 在哪一段，再去掉绝对值。殊途同归，最后都要验。）

## 6. 求 n

每个留下的 P：n = |P − A| + |P − B|
先取绝对值，再相加。

## 7. 人话怎么列式（会写即可）

| 人话 | 先写成 |
|---|---|
| 几倍 | PB = k · PA |
| 等距 | PA = PB |
| 比 PA:PB = m:n | n · PA = m · PB |
| 多 / 少多少 | PB = PA ± d |
| 几倍多 / 少多少 | PB = k · PA ± d |

先写成带 |P−A|、|P−B| 的式子，再展开计算。

## 8. 展开之后的心算

有括号先打开；打开后把含 P（或 x）的挪一边、常数挪一边；再除。
常见样子：mx + a = nx − b，或 m(x+a)=n(x−b) 等。
```
