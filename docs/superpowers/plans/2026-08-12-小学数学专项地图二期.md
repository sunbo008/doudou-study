# 小学数学专项地图二期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成六年级上下册细知识点地图、分班高频横向题及可重复运行的结构校验。

**Architecture:** Markdown 知识正文仍是唯一事实来源；教材目录基线只记录覆盖证据，双视图只导航。一个 Python 标准库脚本只读解析 frontmatter、正文标题和 Markdown 链接，验证 ID、例题结构、难度、核验状态与索引覆盖。

**Tech Stack:** Markdown、YAML 风格 frontmatter、Python 3 标准库 `unittest`、Git。

## Global Constraints

- 六年级教材映射以 `docs/资料/小学数学封面.jpg`、`6-目录1.jpg`、`6-目录2.jpg` 为 `verified_book` 证据。
- 一个 `kp_*.md` 只承载一个可独立教学与测评的能力；跨专项正文只维护一份。
- active 条目至少有 L1、L2；核心及分班高频条目必须有 L3、L4。
- 每道实际例题必须含题目、难度、解题技巧、步骤要点、避坑思路、答案。
- 不引入数据库、第三方 Python 依赖或自动出卷功能。
- 不复制教材原文或整页习题；题目必须自行编写。
- 规格：`docs/superpowers/specs/2026-08-12-小学数学专项地图二三期-design.md`。
