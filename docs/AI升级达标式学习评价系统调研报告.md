# AI 升级达标式学习评价系统调研报告

> 版本：1.0
>
> 日期：2026-08-04
>
> 研究对象：中国初中生的形成性评价、即时反馈、学习进阶诊断与 AI 学习陪练
>
> 核心参考：Attali & Arieli-Attali, *Validating Classifications From Learning Progressions: Framework and Implementation*, ETS RR-19-18

## 一、执行摘要

传统考试能够给出总体成绩，却经常把不同类型的学习状态压缩成一个总分。同样是 75 分，可能分别来自概念不清、计算不稳、迁移不足、书写不规范或审题失误。总分可以用于选拔和总体比较，却难以直接回答三个对学习更重要的问题：

1. 学生对这个具体知识领域发展到了哪个阶段？
2. 哪项能力属性构成了当前瓶颈？
3. 下一次最小而有效的学习行动是什么？

本报告提出，将现有的“AI 答辩式录音学习”进一步抽象为一个更基础的系统：

> **领域学习进阶 + 技能图谱 + 属性诊断 + 渐进提示 + 独立复测 + 延迟升级**

AI 答辩、纸笔作答、口述、错题分析和录音只是采集学习证据的不同方式。系统的真正核心不是让学生与 AI 聊得更久，而是可靠地识别学生当前状态，立即提供下一步行动，并让学生看见自己从“需要帮助”走向“独立、迁移和稳固”的真实进步。

ETS 报告为这一方向提供了重要的测量学约束。学习进阶不能只是一张由专家凭直觉画出的等级表，也不能因为学生偶然答对几题就宣布“升级”。一个可用于教学决策的分类体系，至少需要同时验证：

- 题目被分到某个进阶层级是否一致、合理；
- 学生被分到某个层级能否在不同题卷中复现；
- 高层级题目是否总体更难；
- 学生是否能稳定答对本层及以下题目，同时在更高层题目上显著下降；
- 分类是否与外部表现、真实认知过程和后续学习相符。

本报告的总体判断是：

- **方向成立**：用学习进阶替代单一总分来支持形成性教学，具有明确理论基础和初步实证支持。
- **不能直接照搬**：ETS 研究只验证了一个有理数学习进阶在特定测评系统、学校和样本中的一次实现，并没有验证面向中国初中全学科的通用等级体系。
- **应从窄领域 MVP 开始**：首个试点宜选择知识依赖较清晰、答案可核验、题目可生成变式的数学单元，而不是一开始覆盖全部学科。
- **激励必须依附真实掌握**：升级、经验值和反馈只奖励独立性、迁移和延迟保持，不奖励对话轮数、学习时长、抄写量或有提示时的正确率。

## 二、研究问题与证据边界

### 2.1 本报告回答的问题

1. ETS 的学习进阶分类验证框架具体解决什么问题？
2. 该框架对“升级达标式学习评价”提出了哪些硬约束？
3. 如何把即时反馈、学习动机和认知诊断整合为一个适合中国初中生的系统？
4. 产品最小可行版本应包含哪些对象、流程、算法和界面？
5. 上线前应如何证明系统给出的层级和属性判断可信，并且真的改善学习？

### 2.2 三类证据等级

为避免把合理设想写成已证实结论，本报告使用以下标记：

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A：直接证据 | ETS 报告或引用的实证数据直接支持 | 四格验证框架、693 人样本、分类一致性结果 |
| B：跨研究支持 | 学习科学、动机和 AI 教育研究支持组件，但未验证整套系统 | 显性提取、即时反馈、好奇心、渐进提示 |
| C：待验证假设 | 基于证据作出的产品设计推导 | 升级动画会提高坚持率、属性面板会提升学习快乐 |

尤其需要强调：**“能够更精细地诊断”不自动等于“能够提升学习效果”，“能够提升短期使用兴趣”也不自动等于“能够提高延迟后的独立表现”。**

## 三、为什么总分不足以指导下一步学习

### 3.1 总分发生了信息压缩

传统考试把多个知识点、多种认知层级和不同错误来源合并为一个数字。总分适合回答“总体表现如何”，但不擅长回答“为什么错”和“接下来学什么”。

一个 75 分至少可能对应以下画像：

| 学生 | 概念 | 常规应用 | 迁移 | 规范 | 可能的下一步 |
|---|---|---|---|---|---|
| A | 强 | 强 | 弱 | 强 | 陌生情境和建模 |
| B | 弱 | 强 | 弱 | 强 | 概念辨析和错解解释 |
| C | 强 | 强 | 强 | 弱 | 单位、步骤和书面表达 |
| D | 中 | 中 | 中 | 中 | 定位具体前置知识缺口 |

如果四名学生只收到“继续刷一套 75 分难度的卷子”，评价就没有转化为教学决策。

### 3.2 年级、成绩和真实进阶并不等价

ETS 研究中的六至八年级学生已经学过分数与小数，但三个年级平均正确率分别约为 66%、68% 和 66%，年级效应并不显著。作者认为，这可能与进入初中后课程重点转向代数、对有理数的练习减少有关。

这说明“正在读八年级”不意味着所有七年级前置知识都稳定掌握。评价系统应允许学生在某个领域回到前置节点修复，而不是用年级标签代替知识状态。

## 四、ETS 报告解读

### 4.1 学习进阶是什么

ETS 将学习进阶（Learning Progression, LP）定义为：学生在某一领域中，理解和能力朝向熟练水平发展的层级或步骤。它既可以表达要学什么，也可以说明各概念和技能之间如何连接，从而支持教学规划、形成性评价和补救教学。

报告最关键的观点是：

> 学习进阶本质上是关于“学生通常如何发展”的理论，因此必须被操作化为可观察任务，并接受数据检验。

只有当每一级都写成可观察行为，题目能够引出对应行为，测量模型能够根据作答证据分类学生时，学习进阶才从概念图变成可用于教学的评价工具。

### 4.2 ETS 的四格验证框架

ETS 用两个对象和两个质量维度组成四格框架：

|  | 题目分类 | 学生分类 |
|---|---|---|
| **信度：是否一致** | 不同专家能否把同一题分到相近层级 | 学生换一组等价题后是否仍被分到相近层级 |
| **效度：是否符合数据和用途** | 层级越高的题是否总体越难，题目是否真正调用该层能力 | 分类是否与实际作答、外部成绩及本层掌握预期相符 |

四格不是四个可任选的指标。题目分类是学生分类的基础，信度又是效度的前提。即使模型能把学生分组，如果题目层级本身不稳定，或者换一套题分类就改变，这个等级也不能安全地用于推荐学习任务。

ETS 还区分两种学生分类效度：

- **相对效度**：高层学生是否总体比低层学生表现更好；
- **绝对效度**：被归为 L4 的学生是否真的能以较高概率答对 L4 及以下题目，而不只是比 L3 学生稍好。

对升级制而言，绝对效度尤其重要。系统不能因为学生比别人强就显示“已掌握”，而必须检查其是否达到该层级承诺的可观察表现。

### 4.3 实证研究设计

| 项目 | ETS 实施情况 |
|---|---|
| 领域 | 分数、小数及有理数概念与运算 |
| 学习进阶 | 从二等分、部分-整体理解，到表示流畅、乘性结构和情境建模的 0-5 级进阶 |
| 学生 | 美国新泽西州一所中学六至八年级共 693 人 |
| 样本特征 | 数学成绩约高于州平均 0.43-0.54 个标准差，属于相对高表现样本 |
| 题库 | 50 个题目模型，每个模型 8 个实例，共 400 题 |
| 题卷 | 四套互不重叠的题卷；每名学生作答其中一套共 100 题，分两次完成 |
| 时间 | 每次机房测试含说明和后测问题的中位完成时间为 20 分钟；单题实际作答中位数约 13 秒 |
| 题目分级 | 两位熟悉该进阶的内容专家独立判断题目所需的最低层级，再讨论裁决分歧 |
| 学生分级 | 使用带层级约束的认知诊断模型，根据后验概率分类 |
| 外部标准 | 一年前的州数学统考成绩 |

该研究针对的是基础数感和运算流畅度，大量题目作答时间很短。它不能直接证明开放作文、复杂证明、实验操作或口头答辩也能用同样题量和模型进行可靠分类。

### 4.4 主要结果

#### 题目分类

- 两名专家对 400 题的加权 Kappa 为 0.90；仅看双方均认为适用于该进阶的题，Kappa 为 0.86。
- 21% 的题最终被判定为不适用于该有理数进阶，剩余 316 题进入后续分析。
- 各层题量很不均衡，其中 L2 和 L3 仅占全部题目的 3% 和 6%。

这说明建立题库时，**允许题目“不属于这个技能图谱”**非常重要。不能为了让数据库完整而强行把所有题塞入某个层级。

#### 层级对题目难度的解释力

- 纳入学习进阶层级后，题目模型的正确率方差减少 62%，题目实例方差减少 23%，整体题目方差减少 57%。
- 对反应时间的整体题目方差解释约为 54%。
- 层级越高，题目总体越难、作答越慢，符合学习进阶的基本预测。

这为该有理数进阶的题目侧效度提供了支持，但仍有大量难度差异来自层级以外的因素，例如题面、数字、情境和具体实例。

#### 学生分类

- 75% 的学生在某一层级上的后验概率至少达到 89%；90% 的学生在某一层级上的概率至少达到 66%。
- 51% 的学生被归入最高的 L5；L4 至 L0 分别约占 10%、11%、4%、10% 和 11%，另有 3% 低于 L0。
- 学生层级与本次测验正确率相关 0.89，与州统考成绩相关 0.74。
- 用两组题目分别估计学生层级，加权 Kappa 为 0.78，相关为 0.80，说明分类具有较高一致性。

#### 绝对掌握模式

学生层级达到或超过题目层级时，正确率总体显著高于学生层级低于题目层级时的正确率，两组之间约有 40 个百分点差异。但最高 L5 出现异常：被归为 L5 的学生在 L5 题上的正确率只有约 60%，明显低于较低层级常见的 80% 以上。

作者据此提出 L5 定义可能过宽，应拆成两个层级。这一结果非常重要：**验证不是给既有等级盖章，而是允许数据否定并重构等级。**

### 4.5 ETS 研究的限制

1. 样本来自一所数学表现较高的学校，不能直接代表一般学生或中国初中生。
2. 学习进阶原本描述更低年级的有理数发展，但测量对象是已经接受过相关教学的初中生。
3. 研究是横断面分类，不能直接证明同一学生确实按 L1、L2、L3 的顺序发展。
4. L2、L3 题目较少，对低表现样本的分类能力仍不确定。
5. 多个题目实例来自相同题目模型，部分局部依赖降低了模型拟合。
6. 最高层定义过宽，说明即便专家一致，层级理论仍可能需要修订。
7. 报告验证的是“特定进阶 + 特定题库 + 特定模型 + 特定用途”的组合，不是学习进阶方法在所有场景中的普遍有效性。

## 五、从“多巴胺”到可持续学习动机

### 5.1 不把多巴胺等同于快乐按钮

电玩吸引力不能只解释为“获胜简单，所以释放多巴胺”。多巴胺系统与奖励预测、显著性、学习更新、动机和行动选择有关，而不是单纯产生快乐。太容易的游戏同样会无聊；真正稳定的吸引力往往来自难度合适、行动可控、反馈及时、进步可见和失败可恢复。

因此，学习系统不应追求刺激强度，而应构造以下循环：

> 明确小目标 -> 主动尝试 -> 即时而克制的反馈 -> 看见真实进步 -> 独立过关 -> 解锁下一步

### 5.2 好学生的“快乐复利”

学习表现较好的学生常处于一个正循环：

> 前置知识稳定 -> 新内容认知负荷较低 -> 更容易成功 -> 胜任感增强 -> 更愿意投入 -> 前置知识继续积累

这不意味着成绩暂时落后的学生缺乏意志力。基础缺口、长期过难、反馈延迟、错误羞耻和目标不可见，都可能让学习长期处于“努力但没有升级证据”的状态。

### 5.3 升级制应奖励什么

可以奖励：

- 从需要三级提示变成只需一级提示；
- 从能够识别答案变成能够闭卷提取；
- 从会做同型题变成能做陌生变式；
- 从当天会做变成一周后仍能独立完成；
- 找到并补上真正的前置知识缺口。

不应重点奖励：

- 学习时长、点击次数和对话轮数；
- 连续签到和公开排名；
- 抄写量和听录音次数；
- 有 AI 提示时的正确率；
- 为了刷等级而重复同一模板。

升级必须对应真实能力证据，否则短期的游戏化快感会反过来破坏评价可信度。

## 六、拟议系统模型

### 6.1 三层结构

#### 第一层：领域技能图谱

表达知识点、前置关系和可组合关系，例如：

```text
有理数概念
├── 分数是一个数
├── 分数与小数互化
├── 乘性关系
└── 情境建模
    └── 比例与函数前置
```

技能图谱回答“学什么”和“哪里可能是前置缺口”。它不应只按教材章节平铺，也不应由大模型自动生成后直接上线。教师、教研员和测量专家需要共同确认结构。

#### 第二层：领域学习进阶

可以用一个通用骨架帮助设计，但不能把它当作所有学科共用的固定金字塔：

| 层级骨架 | 可观察表现 |
|---|---|
| P0 证据不足 | 尚无足够作答，不能分类 |
| P1 识别 | 能辨认正确概念、例子或步骤 |
| P2 提取与再现 | 能闭卷说出事实、公式或基本步骤 |
| P3 解释与表示 | 能解释依据，并在文字、图、式之间转换 |
| P4 常规应用 | 能独立完成典型任务 |
| P5 迁移与综合 | 能处理变式、陌生材料和多知识点任务 |

实际实施时，数学函数、语文论证、英语阅读和化学实验必须分别定义自己的层级、典型错误和证据任务。部分能力可能并非严格线性，不能为了界面整齐强迫它们形成单链。

#### 第三层：横向属性向量

学生不是简单“处于 P4”，还需要显示 P4 是怎样形成的：

| 属性 | 诊断问题 |
|---|---|
| 准确 | 核心结论、计算和事实是否正确 |
| 独立 | 使用了多少提示，是否依赖答案 |
| 原理 | 能否解释理由、证据和条件 |
| 规范 | 符号、单位、步骤、文本证据是否完整 |
| 辨析 | 能否发现错解、区分相似概念 |
| 迁移 | 换表述、数字、材料或情境能否应用 |
| 保持 | 延迟后是否仍能独立完成 |
| 校准 | 自己判断的掌握程度是否接近实际表现 |

作答速度只作为辅助数据。除非课程目标明确要求自动化和流畅度，否则不能把慢等同于弱，更不能因此惩罚谨慎学生、阅读困难学生或需要合理便利的学生。

### 6.2 题目证据模型

每道题至少需要以下元数据：

```text
题目 ID
领域与知识节点
所需最低进阶层级
主要与次要能力属性
前置节点
正确答案和评分规则
常见错误及对应提示
允许的作答方式
是否适合即时、迁移或延迟复测
证据来源与审核人
```

这相当于认知诊断中的 Q 矩阵或证据中心设计中的“任务-证据”映射。AI 可以辅助生成候选标签，但初期至少应由两名学科专家独立判断并处理分歧。模型预测能力不能代替内容效度审核。

### 6.3 学生状态不是一个永久标签

系统输出应包含：

- 当前最可能层级；
- 分类不确定性；
- 支持该判断的最近证据；
- 已掌握与未掌握的属性；
- 下一步建议任务；
- 何时需要延迟复测。

不应显示“你就是 L2 学生”，而应显示：

> 在“一元一次方程实际建模”节点上，目前证据支持 P2-P3；常规运算已独立，数量关系表示仍需要提示。完成两道不同情境的独立建模题后重新判断。

这样可以避免把暂时状态固化为能力或智力标签。

## 七、升级与反馈机制

### 7.1 建议的证据门

MVP 阶段可以采用可解释的业务规则，不必一开始就部署复杂模型：

1. **独立门**：至少在不同表述的任务中独立表现；
2. **解释门**：能够说明关键步骤、条件或证据；
3. **迁移门**：完成一道改变情境或组合关系的任务；
4. **保持门**：经过间隔后再次独立完成。

通过前三道门可标记“当前可用”，通过保持门才标记“相对稳固”。具体题量、正确率和间隔不能直接照抄 ETS 的 67%-80% 讨论阈值，必须针对学科、题型、错误代价和本地数据验证。

### 7.2 失败不清空等级

一次失败可能来自粗心、题意歧义、偶然猜测、知识遗忘或真正的概念缺口。合理处理方式是：

- 降低该节点的证据置信度；
- 标记具体错误和使用的提示；
- 安排一题有区分力的复核题；
- 只有持续出现一致证据时才调整层级。

### 7.3 即时反馈协议

反馈遵循四步：

1. 指出一个已经正确的部分；
2. 只定位一个最关键的错误；
3. 给最小必要提示；
4. 要求学生重新作答，并在关闭提示后换题复测。

提示阶梯为：重述卡点 -> 关键词 -> 下一小步 -> 相似例子 -> 完整答案与错误对照。系统记录最高提示级别，把“少用提示仍能完成”作为进步证据。

## 八、评价节奏与角色分工

### 8.1 四种评价事件

| 事件 | 时长 | 作用 | 是否升级 |
|---|---:|---|---|
| 学习中微诊断 | 1-3 分钟 | 定位当前卡点，触发提示 | 否，仅更新证据 |
| 课后小关卡 | 5-10 分钟 | 检查独立与常规应用 | 可暂时升级 |
| 周度混合挑战 | 10-20 分钟 | 检查辨析、迁移和知识连接 | 可升级或要求复核 |
| 延迟 Boss 题 | 按学科设计 | 检查保持和综合应用 | 决定是否稳固 |

大型考试仍有价值，用来评估限时、综合和统一条件下的表现；形成性系统负责回答下一步教学。两者是互补关系，而不是用大量微测验替代全部考试。

### 8.2 AI、教师和测量模型的边界

- **AI**：进行自然语言追问、生成经审核模板的变式、识别候选错误并实施渐进提示；
- **教师/教研员**：定义学习进阶、审核题目证据映射、处理开放题和争议答案；
- **测量模型**：综合多次作答估计状态和不确定性；
- **学生**：通过独立作答、解释、迁移和延迟复测提供证据；
- **家长**：查看行动建议和进步趋势，不依据一次分类贴标签或比较排名。

AI 不应同时拥有出题、给答案、评分、决定层级和宣布掌握的全部权力。

## 九、适合中国初中生的展示方式

### 9.1 学生端

学生首先看到的不是缺陷清单，而是：

```text
今天打通：整式运算 - 去括号
独立性：提示 2 -> 提示 0
仍待解锁：含参数的变式
下次挑战：3 天后 1 道混合题
```

推荐采用个人进步图，不采用公开排行榜。升级动画可以存在，但升级依据必须可点击查看，并能解释“是哪几次独立表现支持了这个判断”。

### 9.2 教师端

教师需要看到：

- 班级在每个知识节点的分布和不确定比例；
- 共性前置缺口和典型错误；
- 哪些学生适合分组补救、常规练习或迁移挑战；
- 哪些题目可能分层错误或产生异常作答；
- 推荐的下一节课活动，而不是更多原始数据。

### 9.3 家长端

家长端以“状态 + 证据 + 下一步”为主：

> 分数与小数互化已经独立；实际建模仍需一级提示。本周不需要增加整套试卷，建议完成两道生活情境题并在周末无提示复测。

不展示智力推断、性格标签、同班排名和无法解释的百分比。

## 十、验证方案：把 ETS 四格框架转成产品门槛

### 10.1 题目分类信度

需要检查：

- 两名以上专家对题目最低层级和属性标签的一致性；
- 分歧是否集中在某些层级边界；
- AI 生成的不同实例是否真的测量相同能力；
- 是否允许“不适用于本进阶”的题目退出。

Kappa 等统计量用于发现问题，而不是单独作为上线通行证。尤其要审查“专家高度一致但共同采用了错误理论”的可能性。

### 10.2 题目分类效度

需要检查：

- 高层级题总体是否更难，但不存在大量逆序；
- 学生解题过程是否实际调用预期知识和策略；
- 同一题目模型的变式是否引入了额外语言、计算或文化负担；
- 开放题评分是否与人工评分一致；
- 层级是否过宽、过窄或题量严重不均。

### 10.3 学生分类信度

需要检查：

- 更换等价题卷后分类是否稳定；
- 短时间重复测量是否出现不合理跳级；
- 分类是否过度受某一道题、某种题型或作答速度影响；
- 分类概率是否校准，低置信度学生是否被明确标为“证据不足”。

### 10.4 学生分类效度

需要同时验证：

- **相对关系**：层级更高者是否在相关任务上总体表现更好；
- **绝对掌握**：学生是否真正答对本层及以下的大部分任务；
- **外部关系**：是否与教师判断、规范测试和真实作品存在合理关系；
- **教学效用**：依据诊断实施不同教学后，是否比统一作业带来更好的延迟学习；
- **纵向转变**：同一学生是否在教学后沿合理路径发展，而不是模型随机跳动；
- **后果公平**：分类错误是否对基础弱、方言、阅读困难或不同设备条件的学生造成系统性不利。

## 十一、分阶段试点路线

### 阶段 0：选择窄领域

建议首个领域为七年级数学中的一个基础单元，例如有理数运算、一元一次方程或整式运算。选择标准：

- 前置关系清晰；
- 答案和过程容易核验；
- 能生成同构题与迁移题；
- 教师能够提供常见错误；
- 延迟效果可以在数周内测量。

### 阶段 1：构念与认知访谈

1. 教师和教研员定义 4-6 个领域层级；
2. 为每层写出学生“知道什么、能做什么、常见误解是什么”；
3. 建立题目-层级-属性映射；
4. 让少量不同水平学生边做边说，检查实际解题过程是否符合预期；
5. 根据访谈拆分过宽层级，删除无法区分的题。

### 阶段 2：题库与分类验证

- 每个关键边界准备足够的不同题目模型，而不只是换数字；
- 设置等价题卷，检验题目和学生分类一致性；
- 比较规则模型、IRT/CDM 与教师判断；
- 报告后验概率或置信区间，不只输出一个等级；
- 对不同年级、基础水平和语言负荷进行分组检查。

样本量应由模型复杂度、层级数量、每层人数和目标精度共同决定，不能套用固定人数。样本不足时宁可使用透明业务规则，也不要用复杂模型制造虚假精确。

### 阶段 3：四周教学效果试点

在取得监护人和学生知情同意的前提下，选择难度相近的知识组进行对照：

- 一组使用“诊断 -> 个性化提示 -> 独立复测”；
- 一组采用原有复习方式；
- 两组记录实际用时；
- 比较即时测验、7 天延迟测验和陌生变式；
- 同时记录压力、反感、自信和主动完成率；
- 统计 AI 错误、直接索取答案、过度提示和错误分级事件。

主要成功指标应是延迟后的无 AI 独立表现，而不是练习时正确率、对话量或产品停留时间。

### 阶段 4：逐学科扩展

数学试点有效也不能直接复制到全部学科：

- 语文需要文本证据、论证质量和开放评分；
- 英语需要把听说读写分开建模；
- 物理、化学需要单位、图示、实验条件和过程证据；
- 历史、道法需要材料对应、因果和观点边界；
- 体育、艺术、劳动与实验操作必须采集真实表现，不能靠聊天或录音替代。

## 十二、关键风险与控制措施

| 风险 | 可能后果 | 控制措施 |
|---|---|---|
| 假精确 | 把有限作答包装成 87% 掌握率 | 显示证据量、不确定性和复核条件 |
| 固化标签 | 学生把暂时层级理解为能力上限 | 用节点状态，不给人格和智力标签 |
| 刷级 | 重复模板获得虚假升级 | 强制不同题模、迁移题和延迟复测 |
| 技能碎片化 | 微技能全绿但综合任务失败 | 设置跨节点 Boss 任务和真实情境 |
| AI 幻觉 | 错误答案、错误提示和错误评分 | 绑定教材答案、题目规则和人工抽检 |
| 速度偏差 | 谨慎或有学习困难的学生被低估 | 速度降为辅助证据，提供合理便利 |
| 过度测量 | 即时反馈变成持续考试压力 | 微诊断短时、可退出，不公开排名 |
| 教学窄化 | 教师只教系统能测的内容 | 保留作品、讨论、实验和教师观察 |
| 隐私风险 | 未成年人声音和学习画像泄露 | 最小收集、本地优先、短期保存、监护同意 |
| 算法不公平 | 某些群体被系统性误分类 | 分组检验、人工复核和申诉更正机制 |

## 十三、MVP 建议

首版只实现以下能力：

1. 一个数学单元的专家审核技能图谱；
2. 4-6 个可观察的领域进阶层级；
3. 每题明确的答案、常见错误和五级提示；
4. 规则化的独立、解释、迁移和保持四道证据门；
5. 学生端显示当前证据、最小短板和下一关；
6. 教师端显示班级节点分布和共性错误；
7. 两套等价题卷与延迟复测；
8. 全量记录 AI 错误、提示使用和分类变化；
9. 不使用公开排行榜、连胜惩罚和自动人格判断；
10. 在收集足够数据之前，不上复杂黑箱知识追踪模型。

这比一开始建设全学科知识图谱、自动出题和深度知识追踪更慢，但能首先回答最重要的问题：**系统所显示的“升级”，究竟是不是可信的学习进步。**

## 十四、结论

我们讨论中的直觉可以被转化为一个严谨命题：学生的学习动力不只来自最终分数，而来自持续获得“我在哪里、为什么卡住、下一步是什么、我是否真的变强”的可信反馈。

ETS 报告支持用学习进阶组织形成性评价，也证明在有理数领域中，经过专家分题、题卷设计和认知诊断建模，可以获得具有较好一致性和效度证据的学生层级分类。但报告同样展示了反面事实：最高层可能定义过宽、题量可能不均、样本可能偏高、横断面分类不能证明发展路径。学习进阶必须持续被数据修订。

因此，项目不应被定义为“用 AI 给学生打更多分”，而应被定义为：

> 建立一个以教学决策为目的、以独立表现为证据、以即时反馈为交互、以延迟迁移为升级条件、并对分类不确定性诚实的学习评价系统。

如果这一体系得到本地验证，它可能改善的不只是测评精度，也包括学生对学习的主观体验：失败不再意味着“我不行”，而意味着“我在这个节点缺少这一项证据”；进步也不再只等到月考公布，而能在每一次真实独立之后被看见。
